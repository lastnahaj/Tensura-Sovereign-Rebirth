# Race Prestige Requirements

Race prestige adds a one-time challenge to a completed race route. The normal prestige conditions still apply: maximum evolution, awakening, required RE, required quests, required boss kills, and a Character Reset Scroll. Each card below comes from the definitions inside TSR's installed SlimeThrone Extras 2.1.2.1 file.

## Current TSR behavior

- Race prestige is available once per supported race.
- Normal prestige requirements still apply.
- `ImmediateRaceQuests` is disabled, so the race questline waits for maximum evolution and its progression trigger.
- No race-prestige races are disabled in the current configuration.
- The current race-prestige reroll mode is `NONE`.
