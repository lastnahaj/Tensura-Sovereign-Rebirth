## Frozen configuration decisions

- Gear Evolution is the authoritative equipment progression. No Apotheosis.
- Sophisticated Storage is physical/base storage; Sophisticated Backpacks is personal storage.
- Tom's Simple Storage is terminal/wireless UI only. Remove/hide every non-required Tom's recipe/block from player progression.
- Great Sage requires the player to actually possess Great Sage (`needGreatSage=true`).
- Tensura: Origins high-tier races are progression-gated and not ordinary random starter selections.
- SlimeThrone Extras owns prestige/Soul Grade/repeatable progression.
- Ascension owns major Unique-to-Ultimate awakening progression and external boss scaling where supported.
- FTB Quests owns the handcrafted campaign; target remains 8 Acts / 32 Chapters / ~512 authored quests.
- Quest Shop is progression-gated; normal mob coin drops are disabled or near-zero.
- LuckPerms owns server permissions. FTB Ranks is not installed.
- No broad biome-overhaul mod in v0.1; preserve Tensura biome/worldgen compatibility.
- MineColonies is pinned to 1.1.1319 for the initial compatibility branch.
- MineColonies warfare/diplomacy alpha features are not made mandatory until multiplayer testing passes.
- ServerCore starts in conservative mode; no aggressive entity/AI tuning before MineColonies/Tensura validation.
- Chunky pre-generation happens only after worldgen/content freeze.
- Jade is configured not to undermine Great Sage/Appraisal information progression.

## Assembly gates

1. Bootstrap exact NeoForge 1.21.1 build and resolve every transitive dependency.
2. Cold-start client smoke test with only Tensura core.
3. Add MineColonies pinned branch and verify colony creation, citizen AI, naming and Tensura integration.
4. Add Gear/Metalworks/Storage and verify item-component persistence across Gear Evolution.
5. Add external bosses/dimensions and validate Ascension EP/skills/resistances.
6. Run worldgen collision/density test before approving When Dungeons Arise.
7. Run non-OP LuckPerms test account through FTB, Tensura, MineColonies, GriefLogger and Essentials commands.
8. Run death/recovery test before approving YIGD.
9. Run rendering/UI test before approving Embeddium.
10. Profile 1, 10 and 25 simulated-player scenarios with spark; tune ServerCore only from observed bottlenecks.
11. Generate the final exact lockfile and server/client split after all gates pass.
12. Only then begin registry-aware FTB Quest implementation against the installed pack.
