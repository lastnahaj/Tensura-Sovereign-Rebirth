# Tempest Protocol Quest Reference

A privately supplied quest archive was reviewed only as a structural reference. It demonstrates a broad campaign divided into onboarding, exploration, settlements, guild work, markets, bosses, dimensions, farming, and optional side activities, supported by shared reward tables and localization.

TSR may use those high-level organization patterns when planning pacing and chapter dependencies. Its quest text, identifiers, rewards, detection logic, and serialized files will be authored independently against TSR's assembled mod versions and verified registries.

The private archive and its source files are not part of this repository and must not be redistributed.
