# Changelog

## TSR v0.1 — Design Freeze

- Locked the project name **Tensura: Sovereign Rebirth**.
- Locked the tagline **Reincarnate. Evolve. Build. Awaken. Rule.**
- Standardized on Minecraft 1.21.1 + NeoForge.
- Established Tensura Reincarnated, SlimeThrone Extras, Ascension, Gear Evolution, MineColonies, and FTB Quests as the primary progression pillars.
- Removed Apotheosis in favor of Gear Evolution.
- Established Sophisticated Storage + Sophisticated Backpacks with Tom's terminal/wireless-only access.
- Added curated decoration, QoL, optimization, and administration layers.
- Established the planned campaign at 8 Acts / 32 Chapters / approximately 512 handcrafted quests.
- Added Quest Shop as the progression-gated economy layer.
- Added LuckPerms as the permission authority.
- Added GriefLogger + Tensura Grief Logger and FTB Backups 3.
- Created the initial TSR branding set.
- Created the v0.1 wiki source.
