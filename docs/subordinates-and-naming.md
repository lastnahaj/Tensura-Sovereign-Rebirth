# Subordinates & Naming

Subordinates are a core part of TSR's nation and character fantasy.

Use the base [Naming](tensura-reference/core-mechanics/naming.md) article for the upstream mechanic; this page explains TSR's subordinate and civilization integrations.

## Systems

- Tensura naming/subordinate mechanics
- Tensura: Better Subordinates
- Tensura Modifications
- Tensura x MineColonies
- FTB Quest integration where supported

## Intended progression

**Name first subordinate**<br>
→ **train subordinate**<br>
→ **subordinate gains/master skills**<br>
→ **create a capable group**<br>
→ **use subordinates in settlement/nation gameplay**<br>
→ **elite guard / envoys / war parties where supported**

Exact quest detection for subordinate milestones must be verified from real APIs/events before implementation.
