# Prestige & Soul Grade

**SlimeThrone Extras is the authoritative prestige system.**

It provides the long-term reincarnation/NG+ loop, including:

- Soul Grade progression,
- race-specific prestige,
- repeatable objectives,
- daily/weekly progression,
- skill permanence/locking,
- long-term replay incentives.

FTB Quests will introduce and contextualize this system but will **not duplicate SlimeThrone's large repeatable quest pool**.

The intended loop is:

**Build a character**<br>
→ **Master meaningful progression**<br>
→ **Prestige**<br>
→ **Improve Soul Grade**<br>
→ **Preserve selected value**<br>
→ **Explore a different progression path**
