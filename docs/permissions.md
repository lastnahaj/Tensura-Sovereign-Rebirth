# Permissions

**LuckPerms is the authority for permissions and ranks.**

## Planned group model

- default/player
- moderator
- administrator
- owner

Servers may add cosmetic/community ranks separately, but those ranks should not bypass RPG progression.

## Test matrix before release

A completely non-OP test account must verify:
- FTB Teams creation/invitations
- claiming/unclaiming
- force-load limits
- FTB Quest administration restrictions
- MineColonies administration
- Tensura admin commands
- Tensura Utilities Manager
- GriefLogger lookup permissions
- teleport/admin utilities
- claim-protection bypass behavior

No permission node will be documented here until it is verified against the installed mod versions.
