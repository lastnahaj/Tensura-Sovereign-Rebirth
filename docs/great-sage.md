# Great Sage

Great Sage is a defining immersion and information system in TSR.

## Planned configuration

Players must actually possess Great Sage before receiving its full functionality. The exact configuration key will be documented only after it is verified against the assembled pack.

## Features used by TSR

- skill/evolution announcements,
- analysis interface,
- creature assessment,
- skill records,
- species observations,
- environmental guidance,
- assisted mastery analysis.

## Design rule

Jade is configured so ordinary tooltips do not undermine the value of Great Sage/Appraisal-style information progression.

Great Sage should feel like a meaningful character milestone, not a universal HUD feature.
