# Magic

TSR's primary external magic system is **Iron's Spells 'n Spellbooks** with the dedicated Tensura compatibility bridge.

## Why Iron's Spells?

The integration is valuable because it makes the external magic system participate in Tensura's resource and combat framework instead of adding an unrelated mana progression.

## MineColonies crossover

MineColonies Mages adds a mage-guard profession using Iron's Spells, creating a clean chain:

**Tensura character systems**<br>
→ **Iron's magic**<br>
→ **MineColonies mage citizens**

Additional magic systems are only added if they provide a distinct role and do not create mandatory duplicate progression.
