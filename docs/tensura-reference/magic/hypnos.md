<p>Puts the target into a deep slumber
</p>
<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p><br/>
</p>
<ul><li>Puts the target into true sleep for 60 seconds (30 seconds if the target has spirit attack null). Target wakes up if they take damage.</li></ul>
<p><br/>
</p>
<h2><span class="mw-headline" id="Mastery_Bonus">Mastery Bonus</span></h2>
<p><br/>
</p>
<ul><li>Casting time reduced to 120 ticks.</li>
<li>Sleep duration increases to 120s (60 seconds if the target has spirit attack null).</li>
<li>Target wakes up after 3 hits instead of 1.</li></ul>
<p><br/>
</p>
<h2><span class="mw-headline" id="Tips">Tips</span></h2>
<p>Attacks that deal purely spirtual damage do not wake up the target. (Ex: True Darkness)
</p><p><br/>
</p>
