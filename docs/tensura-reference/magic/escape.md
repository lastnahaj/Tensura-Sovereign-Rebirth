<p>Allows you to create a kind of checkpoint to which you can return
</p>
<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p><br/>
</p>
<ul><li>Saves the location the player is standing. When activated again within 500 block radius, sends the player back to the saved location with 100 ticks charge time. 10s cooldown. Sneak-activate to remove saved location.</li></ul>
<h2><span class="mw-headline" id="Mastery_Bonus">Mastery Bonus</span></h2>
<p><br/>
</p>
<ul><li>Instant charge time, 1000 block radius and 5s cooldown. When toggled will automatically send the player back to the saved location when their health gets below 10% or MP gets below 1%.</li></ul>
