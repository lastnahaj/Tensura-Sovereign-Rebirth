<p>Summons a spirit which decided to dwell within the user. Switching skill modes changes the elemental summoned. <br/>
</p><p>To switch skill modes, hold <b>alt</b> and press the ability button to select what spirit you'd like to summon.
</p>
<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p><br/>
</p>
<ul><li>Summons the selected spirit. Summons can be <a href="../../bosses/mobs-akash/" title="Mobs/Akash">Akash</a>, <a href="../../bosses/mobs-ifrit/" title="Mobs/Ifrit">Ifrit</a>, <a href="../../bosses/mobs-sylphide/" title="Mobs/Sylphide">Sylphide</a>, <a href="../../bosses/mobs-undine/" title="Mobs/Undine">Undine</a>, and <a href="../../bosses/mobs-war-gnome/" title="Mobs/War Gnome">War Gnome</a></li></ul>
<h2><span class="mw-headline" id="Mastery_Bonus">Mastery Bonus</span></h2>
<p><br/>
</p>
<ul><li>Cast time reduced to 60 ticks</li>
<li>Movement speed debuff reduced <b>(but not gone)</b></li></ul>
