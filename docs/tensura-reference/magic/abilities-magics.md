## In Tensura: Sovereign Rebirth

<span class="tsr-status">Explicit integration</span>

Base Tensura magic remains the primary reference. TSR also installs Iron's Spells 'n Spellbooks with its dedicated Tensura bridge; the external system is documented as an integration, not as a replacement for base magic.
