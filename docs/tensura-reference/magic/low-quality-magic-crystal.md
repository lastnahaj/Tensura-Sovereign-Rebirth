<p>Low Quality Magic Crystals
</p>
<h3><span id="Absorb_.26_Dissolve"></span><span class="mw-headline" id="Absorb_&amp;_Dissolve">Absorb &amp; Dissolve</span></h3>
<p>Like any other Magic Crystal, the Low Quality Magic Crystal can be consumed by using the <a class="mw-redirect" href="../../skills/intrinsic/absorb-dissolve/" title="Abilities/Skills/Absorb &amp; Dissolve">Absorb &amp; Dissolve</a> skill. Consuming this Magic Crystal regenerates 1000 Magicules instantly.
