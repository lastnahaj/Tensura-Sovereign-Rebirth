<p>When you want to be a daemon but don't like the race:
</p>
<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p><br/>
</p>
<ul><li>Same as the Possession skill, with all the same requirements, but it happens instantly between two bodies, with no spiritualizing in between, and the target needs to stay in the magic circle when casting.</li></ul>
<p><br/>
</p>
<h2><span class="mw-headline" id="Mastery_Bonus">Mastery Bonus</span></h2>
<p><br/>
</p>
<ul><li>Allows the possession skill to be learned.</li></ul>
