Syntax Structure:
</big></p><big><ul><li>Forward slash <code>/</code> indicates alternatives.</li>
<li>Parentheses <code>()</code> indicate the expected input.</li>
<li>Square brackets <code>[a/b/c]</code> indicate a required parameter.</li>
<li>Orange parameters <code><span><u>[a/b/c]</u></span></code> indicate an optional parameter.</li></ul></big><big></big><p><big></big>

<h3><span class="mw-headline" id="Ability">Ability</span></h3>
<p><code><b>/tensura get ability [Unique]</b></code> - Shows your unique skill its data
</p>
<div class="collapsible-header"><code><b>/tensura get ability list</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura get ability list magic</b></code> - Shows what magic skills you have
</p><p><code><b>/tensura get ability list battlewill</b></code> - Shows what battlewill skills you have
</p>
<div class="collapsible-header"><code><b>/tensura get ability list skill</b></code>Click to show more filters</div> (shows what skills you have)
<div class="collapsible-content">
<p><code><b>/tensura get ability list skill common</b></code> - shows common skills
</p><p><code><b>/tensura get ability list skill extra</b></code> - shows extra skills
</p><p><code><b>/tensura get ability list skill instrinsic</b></code> - shows instrinsic skills
</p><p><code><b>/tensura get ability list skill resistance</b></code> - shows resistances
</p><p><code><b>/tensura get ability list skill ultimate</b></code> - shows ultimate skills
</p><p><code><b>/tensura get ability list skill unique</b></code> - shows unique skills
</p>
</div>

<h2><span class="mw-headline" id="Preset">Preset</span></h2>
<p><code><b>/skill Preset name [preset] [name]</b></code> - with this command you can change the name of your preset.
</p><p><code><b>/skill Preset set [preset]</b></code> - with this command you can change to one of your presets.
</p>
<h2><span class="mw-headline" id="Set">Set</span></h2>
<p><code><b>/skill set [one of your skills] [preset]</b></code> - with this command you can place one of your skills in a preset of your choice.
</p>
<h2><span class="mw-headline" id="Storage">Storage</span></h2>
<p><code><b>/skill storage [ability]</b></code> - shortcut to opening the selected ability's stomach, if it has one.
</p><p><code><b>/skill storage add [ability]</b></code> - shortcut to adding the items in your main hand to the skill's stomach, if it has one.
</p>

<h2><span class="mw-headline" id="Edit_player">Edit player</span></h2>
<div class="collapsible-header"><code><b>/tensura edit [player]</b></code>Click to show more</div>
<div class="collapsible-content">
<h3><span class="mw-headline" id="Ability_2">Ability</span></h3>
<div class="collapsible-header"><code><b>/tensura edit [player] ability</b></code>Click to show more</div>
<div class="collapsible-content">
<h4><span class="mw-headline" id="Cooldown">Cooldown</span></h4>
<p><code><b>/tensura edit [player] ability cooldown [ability] [amountInSeconds]</b></code> - gives the selected ability of the selected player a cooldown in seconds (for example: amountInseconds 1600 and ability predator, predator will be in cooldown for 1600 seconds)
</p><p><code><b>/tensura edit [player] ability cooldown everything [amountInSeconds]</b></code> - gives all abilities of the selected player a cooldown in seconds (for example: amountInseconds 1600, <b>ALL</b> abilities cooldown will be for 1600 seconds)
</p>
<h4><span class="mw-headline" id="Grant">Grant</span></h4>
<div class="collapsible-header"><code><b>/tensura edit [player] ability grant</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] ability grant all <span><u>[Magic/Battlewill/Skill]</u></span></b></code> - gives all abilities to the selected player, however you can also specify what type of skills (magic, battlewill or skill).
</p><p><code><b>/tensura edit [player] ability grant random <span><u>[Magic/Battlewill/Skill]</u></span></b></code> - gives a random ability or skill unless again specified.
</p><p><code><b>/tensura edit [player] ability grant [Skill]</b></code> - gives the ability entered to the specified player.
</p>
</div>
<h4><span class="mw-headline" id="Mastery">Mastery</span></h4>
<div class="collapsible-header"><code><b>/tensura edit [player] ability mastery</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] ability mastery [skill] [amount]</b></code> - sets the amount of mastery points of the given skill to the given amount (for example: predator and 100 would set my predator mastery points to 100)
</p><p><code><b>/tensura edit [player] ability mastery [skill] max</b></code> - makes the given skill fully mastered
</p><p><br/>
</p>
<div class="collapsible-header"><code><b>/tensura edit [player] ability mastery everything</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] ability mastery everything [amount]</b></code> - sets all the abilities of the given player to the amount given
</p><p><code><b>/tensura edit [player] ability mastery everything max</b></code> - makes all the skills of the given player fully mastered
</p><p><code><b>/tensura edit [player] ability mastery everything <span><u>[Magic/Battlewill/Skill]</u></span> [amount]</b></code> - sets the specified abilities of the given player to the amount given
</p><p><br/>
<code><b>/tensura edit [player] ability mastery everything <span><u>[Magic/Battlewill/Skill]</u></span> max</b></code> - makes the specified abilities of the given player fully mastered
</p>
</div>
</div>
<h4><span class="mw-headline" id="Modelearning">Modelearning</span></h4>
<h4><span class="mw-headline" id="Revoke">Revoke</span></h4>
<div class="collapsible-header"><code><b>/tensura edit [player] ability revoke</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] ability revoke everything <span><u>[Magic/Battlewill/Skill]</u></span></b></code> - takes all abilities of the selected player, however you can also specify what type of skills (magic, battlewill or skill).
</p><p><code><b>/tensura edit [player] ability revoke [Skill]</b></code> - takes away the ability entered from the specified player.
</p>
</div>
<h4><span class="mw-headline" id="Toggle_2">Toggle</span></h4>
<div class="collapsible-header"><code><b>/tensura edit [player] ability toggle</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] ability toggle <span><u>[Magic/Battlewill]</u></span></b></code> [on/off]- toggles the specified skills on or off
</p><p><code><b>/tensura edit [player] ability toggle [Skill] [on/off]</b></code> - toggles the specified skill on or off
</p><p><code><b>/tensura edit [player] ability toggle skill [common/extra/instrinsic/resistance/ultimate/unique] [on/off]</b></code> - toggles the specified skills on or off
</p><p><code><b>/tensura edit [player] ability toggle skill all [on/off]</b></code> - toggles the specified skills on or off
</p>
</div>
</div>

<h3><span class="mw-headline" id="Force_Evo">Force Evo</span></h3>
<div class="collapsible-header"><code><b>/tensura edit [player] awakening</b></code>Click to show more</div>
<div class="collapsible-content">
<p><code><b>/tensura edit [player] forceevo [demonlord/hero]</b></code> - force awakens a player into either demonlord or hero
</p><p><code><b>/tensura edit [player] forceevo race [evolutionOption]</b></code> - force awakens a player into their next evolution (they can pick what evolution option, but its what they evolve into next)
</p>
</div>
</div>
<h3><span class="mw-headline" id="Race_2">Race</span></h3>
<p><code><b>/tensura edit [player] race majin [true/false]</b></code> - sets the <a class="mw-redirect" href="../../core-mechanics/races-alignment/" title="Races/Majin"><b>Majin</b></a> status to true / false for the player's race.
</p>
<h3><span class="mw-headline" id="Resets">Resets</span></h3>
<p><code><b>/tensura edit [player] race [race] [resetStats (true/false)]</b></code> - sets the player race to the selected one and resets their stats (MP, AP, ...) if true.
</p><p><code><b>/tensura edit [player] race [race] [resetStats (true/false)] [grantIntrinsicSkills (true/false)</b></code> - sets the player race to the selected one, resets their stats (MP, AP, ...) if resetStats is true, and grants their new race's <a href="../../skills/other/abilities-skills/" title="Abilities/Skills"><b>Intrinsic Skills</b></a> if grantIntrinsicSkills is true.
</p><p><br/>
</p>
<h3><span class="mw-headline" id="Engravement">Engravement</span></h3>
<p><code><b>/engrave [player] [engravement] [level (number)</b></code> - adds the selected engravement to the held item with set level.
</p>
<h3><span class="mw-headline" id="Worlddata">Worlddata</span></h3>
<p><code><b>/tensura worldData trulyUnique list</b></code> - displays a list of all taken <a class="mw-redirect" href="https://tensura.wiki.gg/wiki/Unique_Skills" title="Unique Skills"><b>Unique Skills</b></a>.
</p>
