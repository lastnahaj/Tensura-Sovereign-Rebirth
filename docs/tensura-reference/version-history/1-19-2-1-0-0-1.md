<h2><span class="mw-headline" id="Changes">Changes</span></h2>
<h3><span class="mw-headline" id="Additions">Additions</span></h3>
<ul><li>Downgrade mixinextra to **0.2.0** to have compatibility with other 1.19.2 mods.</li>
<li>Race menu now shows evolution requirements vaguely instead of their stats.</li>
<li>Palm trees actually spawn now.</li></ul>
<h3><span class="mw-headline" id="Balance">Balance</span></h3>
<ul><li><a href="../../skills/common/farsight/" title="Farsight">Farsight</a> now can increase the analysis distance when mastered.</li>
<li>Spears now can be used with Loyalty.</li></ul>
<h3><span class="mw-headline" id="Quality_of_Life">Quality of Life</span></h3>
<ul><li>Breath-type skills/magics (<a href="../../skills/intrinsic/flame-breath/" title="Flame Breath">Flame Breath</a>, <a href="../../skills/unique/gluttony/" title="Gluttony">Gluttony</a>, <a href="../../skills/unique/predator/" title="Predator">Predator</a>, etc.) now won't attack the user's mount or rider unless those mobs are doing damage.</li>
<li><a href="../../skills/unique/predator/" title="Predator">Predator</a>, <a href="../../skills/unique/gourmet/" title="Gourmet">Gourmet</a> and <a href="../../skills/unique/gluttony/" title="Gluttony">Gluttony</a> now has the 4th mode of Block Mode to consume both Blocks and Fluid.</li>
<li>Added a command to edit one's Severance amount: `/tensura edit stat severance [number]`</li>
<li>Monster Leather D now can be used to craft books.</li>
<li>Reduced bird sounds' volume.</li></ul>
<h3><span class="mw-headline" id="Bug_Fixes">Bug Fixes</span></h3>
<ul><li>Incompatibility regarding World generation and biome.</li>
<li>Unintended speed boost related to <a href="../../skills/common/gravity-flight/" title="Gravity Flight">Gravity Flight</a> and other abilities.</li>
<li>The Default crit multiplier is 2.25 instead of 1.5</li>
<li>Other minor changes.</li></ul>
