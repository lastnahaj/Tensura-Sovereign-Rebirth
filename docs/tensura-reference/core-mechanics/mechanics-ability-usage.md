# Ability Usage

<span class="reference-badge">Base Tensura reference</span> <span class="reference-category">Core Mechanics</span>

<div class="tensura-reference-article">
<div class="mw-content-ltr mw-parser-output" dir="ltr" lang="en"><p><big><big>Tensura: Reincarnated comes with many different ways of utilizing abilities.</big></big>
</p><p><br/>
</p>

<h1><span class="mw-headline" id="Learning">Learning</span></h1>
<p><big><big>Before using an ability, you are required to learn it.</big></big>
</p>
<div class="thumb tright"><div class="thumbinner"> <div class="thumbcaption"><div class="magnify"><a class="internal" href="https://tensura.wiki.gg/wiki/File:SkillLearning.png" title="Enlarge"></a></div>An unlearnt skill <b><a href="../../skills/common/strength/" title="Strength">Strength</a></b></div></div></div>
<p>Unlearnt abilities will show up in grey text in your Ability Menu, and you can hover on the progress bar to see how many points you have. The learning process is straight-forward: equip the ability in any slot and activate it with the corresponding keybind.
</p><p><br/>
A message will appear on the screen, saying that you've become closer to acquiring it.<br/>

</p><p><br/>
Upon reaching 100 Learn Points, you will learn the ability and become able to use it. Its color in the Menu will also change depending on its type.<br/>

</p><p>Once you have learnt a skill. It will reduce your Max MP by a certain amount depending on the type of skill:
</p>
<ul><li>Common Skills cost 100 MP</li>
<li>Extra Skills cost 1,000 MP</li></ul>
<p><b>Also shown via Obtainment Cost on Every Skill's page</b>
</p><p><br/>
There is a 10% chance that you will fail during your attempt to learn the ability. In that case, the message will <i>not</i> appear. Instead, you will lose between 1 to 3 points and be given a random effect between <b><a class="external text" href="https://minecraft.wiki/w/Blindness" rel="nofollow">Blindness</a></b>, <b><a href="../../skills/common/paralysis/" title="Paralysis">Paralysis</a></b>, and <b><a class="new" href="https://tensura.wiki.gg/wiki/Insanity?action=edit&amp;redlink=1" rel="nofollow" title="Insanity (page does not exist)">Insanity</a></b>.
</p><p>While straight-forward, the process can be rather tedious and time-consuming, especially if you fail often and because you have to remember to use the ability when it's off cooldown. Some of the abilities can make it faster and easier, namely: <b><a href="../../skills/extra/sage/" title="Sage">Sage</a></b>, <b><a href="../../skills/unique/great-sage/" title="Great Sage">Great Sage</a></b>, <b><a href="../../skills/unique/mathematician/" title="Mathematician">Mathematician</a></b>, and <b><a href="../../skills/unique/cook/" title="Cook">Cook</a></b>. The boosts are <i>stacked</i>, meaning having multiple of these will yield more points than having one.
</p>
<h1><span class="mw-headline" id="Mastery">Mastery</span></h1>
<p><big><big>Certain ability modes and uses might require mastery.</big></big>
</p><p>Mastery is a mechanic that is present in every ability, but it's not always a requirement. Some abilities have multiple modes or uses that become available only after fully mastering the said ability. Similarly to <a class="mw-selflink-fragment" href="#Learning">Learning</a>, you gain it by using the ability, however, unlike with learning, there is no chance of failing, and the number of points required to master it is usually higher in return.
</p><p><br/>
Much like learning, it also has abilities that speed up the process: <b><a href="../../skills/extra/sage/" title="Sage">Sage</a></b>, <b><a href="../../skills/unique/great-sage/" title="Great Sage">Great Sage</a></b>, <b><a href="../../skills/unique/mathematician/" title="Mathematician">Mathematician</a></b>, <b><a href="../../skills/unique/fighter/" title="Fighter">Fighter</a></b>, and <b><a href="../../skills/unique/cook/" title="Cook">Cook</a></b>. The boosts are stacked here as well.
</p><p>Players will also gain x2 mastery points when their ability move hits a target (Making it x3 points for each activation, counting the one for pressing the ability button). If the move kills an entity, players will gain another x2 mastery points (making it x5 for the activation).
</p>
<h1><span class="mw-headline" id="Presets">Presets</span></h1>
<p><big><big>It is possible to use 27 skills at once through the use of the 9 presets.</big></big>
</p><p>By default, you can switch presets with <code>Alt + Scroll Wheel</code> and <code>Alt + Preset Number Keybind</code>. Alternatively, you can switch presets through the Ability Menu by <i>double clicking</i> the preset number.
</p><p>A preset can have up to 3 abilities equipped at a time, and those can be a combination of <b><a href="../../skills/other/abilities-skills/" title="Abilities/Skills">Skills</a></b>, <b><a href="../../magic/abilities-magics/" title="Abilities/Magics">Magics</a></b>, and <b><a class="mw-redirect" href="https://tensura.wiki.gg/wiki/Abilities/Battlewills" title="Abilities/Battlewills">Battlewills</a></b>.
</p><p>Interacting with the slots is as follows:
</p>
<ul><li><b>Left Clicking</b> after selecting a learnt ability will equip it in the clicked slot.</li>
<li><b>Right Clicking</b> a slot that contains an ability will select it and show that ability's information.</li>
<li><b>Middle Clicking (Mouse Wheel)</b> will remove the ability contained in the slot.</li></ul>

<h1><span class="mw-headline" id="Ability_Modes">Ability Modes</span></h1>
<p><big><big>Many abilities have more than one usage.</big></big>
</p><p>By default, the keybind to switch ability modes is <code>Alt + Skill Slot Key</code>. For example, if <b><a href="../../skills/unique/predator/" title="Predator">Predator</a></b> was in the third slot, you would press <code>Alt + C</code>.
</p><p>Some modes require the ability to be <i>mastered</i>. For this, refer to the <a class="mw-selflink-fragment" href="#Mastery">Mastery</a> section.
</p>
<h1><span class="mw-headline" id="Ability_Activation_Types">Ability Activation Types</span></h1>
<p><big><big>Abilities have different ways of using them.</big></big>
</p><p>This section describes the terms used on the wiki. They are not explicitly mentioned in the mod.
</p>
<ul><li><big><b>Active - Press:</b></big> implies the ability has to be <i>pressed</i> to use it.</li>
<li><big><b>Active - Hold:</b></big> implies the ability has to be <i>pressed and held</i> to use it.</li>
<li><big><b>Passive - In Slot:</b></big> implies the ability cannot be activated manually, but instead has to be <i>equipped in a active slot</i> to be activated.</li>
<li><big><b>Passive - Toggle:</b></big> implies the ability has to be <i>toggled on in the Ability Menu</i>, which can be done through the checkbox next to the ability's icon.</li>
<li><big><b>True Passive:</b></big> implies the ability is <i>always activated</i> and cannot be turned off.</li></ul>
