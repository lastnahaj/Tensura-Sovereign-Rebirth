<h1><span id="WARNING.21_This_is_a_Gamerule_which_is_not_on_by_default._See_the_Usage_section_for_more_info"></span><span class="mw-headline" id="WARNING!_This_is_a_Gamerule_which_is_not_on_by_default._See_the_Usage_section_for_more_info">WARNING! This is a <a href="../../gamerules/config-gamerules/" title="Config/Gamerules">Gamerule</a> which is not on by default. See the Usage section for more info</span></h1>
<h2><span class="mw-headline" id="Obtainment">Obtainment</span></h2>
<ul><li>Defeating the following <b>bosses</b>:
<ul><li><a href="../../bosses/mobs-ifrit/" title="Mobs/Ifrit">Ifrit</a></li>
<li><a href="../../bosses/mobs-elemental-colossus/" title="Mobs/Elemental Colossus">Elemental Colossus</a></li>
<li><a href="../../bosses/mobs-charybdis/" title="Mobs/Charybdis">Charybdis</a></li>
<li><a href="../../bosses/mobs-orc-disaster/" title="Mobs/Orc Disaster">Orc Disaster</a></li>
<li><a href="../../bosses/mobs-hinata-sakaguchi/" title="Mobs/Hinata Sakaguchi">Hinata</a></li>
<li><a href="../../bosses/mobs-gazel-dwargo/" title="Mobs/Gazel Dwargo"> Gazel Dwargo</a></li></ul></li>
<li>Reach your <b>final evolution</b></li>
<li><a href="../races-awakening/" title="Races/Awakening">Awaken</a> as either <b>True Demon Lord</b> or <b>True Hero</b></li></ul>
<p>Finish up by using a <b><a href="../mechanics-reset-scrolls/" title="Mechanics/Reset Scrolls">Character Reset Scroll</a></b>
</p>
<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<ul><li>Flexing as the Reset Counter comes with a Rank/Medal system showing up in your Status Menu.</li>
<li>When the <a href="../../gamerules/config-gamerules/" title="Config/Gamerules">Gamerule</a> <code>resetCounterBonusUnique</code> is higher than 0: Upon resetting, the player will gain bonus Unique Skills based on the amount of Reset Counter they have:</li></ul>
<p>If the value of the gamerule is 1, it will be 1 extra <a class="mw-redirect" href="https://tensura.wiki.gg/wiki/Unique_Skills" title="Unique Skills">unique</a> every single reset. (so you then get 2 uniques when you have reset)
<br/>If the value of the gamerule is 5, it will be 1 extra unique every <b>5 resets</b> (e.g. 2 bonus uniques at 10 resets)
</p>
<h2><span class="mw-headline" id="Penalty">Penalty</span></h2>
<ul><li>This penalty only applies when the <a href="../../gamerules/config-gamerules/" title="Config/Gamerules">Gamerule</a> <code>resetIncompletePenalty</code> is higher than 0.</li></ul>
<p>When using any type of <b><a href="../mechanics-reset-scrolls/" title="Mechanics/Reset Scrolls">Mechanics/Reset Scrolls</a></b> while the requirements for Obtainment are not met, the number of reset counted will be reduced by the number set for the above gamerule.
</p><p>When all requirements are met the penalty won’t apply, so you will be able to use race/skills reset without losing reset counter
</p>
