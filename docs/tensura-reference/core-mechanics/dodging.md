<h2><span class="mw-headline" id="Important_Note">Important Note</span></h2>
<ul><li>By default is disabled, use the gamerule [playerManualDodging] to enable it.</li></ul>
<h2><span class="mw-headline" id="How_does_Dodging_work">How does Dodging work</span></h2>
<ul><li>Upon dodging, the player will gain few ticks of invulnerability, base dodge invulnerability is 5 ticks. During this time, the player cannot be hit with damage unless its from the environment, mental/spiritual or big aoe (like explosion, barrier, field) damage and few specific damages tagged as undodgable. Abilities can increase this duraion with the maximum possible is 10 ticks. Dodge Negation can completely ignore this duration.</li></ul>
<ul><li>When pressing Dodge key (default V, this key will make flying/swimming mounts descend when riding one) while on the ground (or in creative flight), the player will small-dash toward the direction the player's movement keys pressed, backstep if standing still. This won't work if the player is crouching, using/casting items, riding, swimming, or jumping.
<ul><li>Dodging force is decided by Dodge Strength (default is 0, a weak base dash when at 0) and the player's Jump Strength decides the vertical force.</li></ul></li></ul>
<ul><li>After dodging, the player will be put into a 1-second cooldown. If the player succeeds dogding an incoming attack, the cooldown is reset to 0.</li></ul>
<p>All of the values used are configurable.
</p>
<h2><span class="mw-headline" id="Abilities_that_affect_dodging">Abilities that affect dodging</span></h2>
<ul><li>[Instant-move] battlewill when mastered will increase Dodge Strength by 0.1 if toggled.</li></ul>
<ul><li>[Martial Master], [Shadow Striker] and [Fighter] will each increase Dodge Strength by 0.25 if toggled.</li></ul>
<ul><li>[Instant-move] battlewill when mastered will increase Dodge Invulnerability by 1 tick if toggled.</li></ul>
<ul><li>[Martial Master], [Shadow Striker] and [Fighter] will each increase Dodge Invulnerability by 2 ticks if toggled.</li></ul>
<ul><li>[Thought Acceleration] and [All-seeing Eye] when mastered will each increase Dodge Invulnerability by 1 tick if toggled.</li></ul>
