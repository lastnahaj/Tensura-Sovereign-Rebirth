<h1><span class="mw-headline" id="About_Rimuru_mode">About Rimuru mode</span></h1>
<p>Rimuru mode is a <a href="../../gamerules/config-gamerules/" title="Config/Gamerules">Gamerule</a> that as the name implies, can turn the person into Rimuru and give him/her the full Rimuru experience.<br/>
<small>Warning, if you turn this on in multiplayer, everyone becomes rimuru because yes, its a gamerule. </small>
</p>
<h2><span class="mw-headline" id="Once_you_activate_the_gamerule...">Once you activate the gamerule...</span></h2>
<p>Every player becomes Rimuru (aka a <a href="../../races/races-slime/" title="Races/Slime">Slime</a>) and gains the following skills: <br/>
</p><p><b>Skills available to learn:</b>
</p>
<ul><li><a class="mw-redirect" href="../../skills/extra/danger-sense/" title="Abilities/Skills/Danger Sense">Danger Sense</a></li>
<li><a class="mw-redirect" href="../../magic/magic-sense/" title="Abilities/Skills/Magic Sense">Magic Sense</a></li></ul>
<p>Skills obtained:
</p>
<ul><li><a class="mw-redirect" href="../../skills/intrinsic/absorb-dissolve/" title="Abilities/Skills/Absorb &amp; Dissolve">Absorb &amp; Dissolve</a> From Slime Race</li>
<li><a class="mw-redirect" href="../../skills/common/self-regeneration/" title="Abilities/Skills/Self Regeneration">Self Regeneration</a> From Slime Race</li>
<li><a class="mw-redirect" href="../../skills/unique/predator/" title="Abilities/Skills/Predator">Predator</a></li>
<li><a class="mw-redirect" href="../../skills/unique/great-sage/" title="Abilities/Skills/Great Sage">Great Sage</a></li>
<li><a class="mw-redirect" href="../../resistances/thermal-fluctuation-resistance/" title="Abilities/Skills/Thermal Fluctuation Resistance">Thermal Fluctuation Resistance</a></li>
<li><a class="mw-redirect" href="../../resistances/pain-nullification/" title="Abilities/Skills/Pain Nullification">Pain Nullification</a></li>
<li><a class="mw-redirect" href="../../resistances/electricity-resistance/" title="Abilities/Skills/Electricity Resistance">Electricity Resistance</a></li>
<li><a class="mw-redirect" href="../../resistances/pierce-resistance/" title="Abilities/Skills/Pierce Resistance">Pierce Resistance</a></li>
<li><a class="mw-redirect" href="../../resistances/physical-attack-resistance/" title="Abilities/Skills/Physical Attack Resistance">Physical Attack Resistance</a></li></ul>
<h3><span class="mw-headline" id="Special_mechanics">Special mechanics</span></h3>
<p><big>These are special mechanics that only work when Rimuru mode is enabled</big> <br/>
</p><p>If the player kills <a href="../../bosses/mobs-shizu/" title="Mobs/Shizu">Shizu</a> using Predator/<a href="../../skills/unique/gluttony/" title="Gluttony">Gluttony</a>, they will obtain <a class="mw-redirect" href="../../skills/unique/degenerate/" title="Abilities/Skills/Degenerate">Degenerate</a> <br/>
</p><p>If the player gains 20k souls, they will obtain <a class="mw-redirect" href="../../skills/unique/merciless/" title="Abilities/Skills/Merciless">Merciless</a>
</p>
