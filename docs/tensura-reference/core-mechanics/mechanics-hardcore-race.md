# Hardcore Race

<span class="reference-badge">Base Tensura reference</span> <span class="reference-category">Core Mechanics</span>

<div class="tensura-reference-article">
<div class="mw-content-ltr mw-parser-output" dir="ltr" lang="en">
<h1><span class="mw-headline" id="About_Hardcore_Races">About Hardcore Races</span></h1>
<p>Hardcore races is a gamerule which makes races <b>significantly harder</b> upon choosing them. The following occurs when hardcore races is toggled on:
</p>
<h2><span class="mw-headline" id="Misc">Misc</span></h2>
<p><a href="../naming/" title="Naming">Named</a> players can not <a href="../races-awakening/" title="Races/Awakening">awaken</a> (aka become True Demon Lord or True Hero) - being Named by the Masses will not prevent you from awakening.
</p>
<h2><span class="mw-headline" id="Affected_races">Affected races</span></h2>
<h3><span class="mw-headline" id="Slime"><a href="../../races/races-slime/" title="Races/Slime">Slime</a></span></h3>
<p>Spawn in blind, need perception sense skill like <a class="mw-redirect" href="../../magic/magic-sense/" title="Abilities/Skills/Magic Sense">Magic Sense</a> to see
</p>
<h3><span class="mw-headline" id="Lizardman"><a href="../../races/races-lizardman/" title="Races/Lizardman">Lizardman</a></span></h3>
<p>Are debuffed in cold places (e.g. peak biomes, taiga's)
</p>
<h3><span class="mw-headline" id="Merfolk"><a href="../../races/races-merfolk/" title="Races/Merfolk">Merfolk</a></span></h3>
<p>Need water to breathe (begins to suffocate on land, just like humans do in water)
</p>
<h3><span id="Wight_.2F_Ghoul"></span><span class="mw-headline" id="Wight_/_Ghoul"><a href="../../races/races-wight/" title="Races/Wight">Wight</a> / <a href="../../races/races-ghoul/" title="Races/Ghoul">Ghoul</a></span></h3>
<p>Will burn in sun even though they are wearing a helmet
</p>
<h3><span class="mw-headline" id="Vampire"><a href="../../races/races-vampire/" title="Races/Vampire">Vampire</a></span></h3>
<ul><li>Will burn in sun even though they are wearing a helmet</li>
<li>Cannot enter bat mode while in the sun</li></ul>
<h3><span id="Orc_Lord_.2F_Orc_Disaster"></span><span class="mw-headline" id="Orc_Lord_/_Orc_Disaster"><a href="../../races/races-orc-lord/" title="Races/Orc Lord">Orc Lord</a> / <a href="../../races/races-orc-disaster/" title="Races/Orc Disaster">Orc Disaster</a></span></h3>
<p>These races gain the hunger effect.
</p>
<ul><li>Hunger III for <a href="../../races/races-orc-lord/" title="Races/Orc Lord">Orc Lord</a></li>
<li>Hunger V for <a href="../../races/races-orc-disaster/" title="Races/Orc Disaster">Orc Disaster</a></li></ul>
<p>Evolving disables the hunger effect
</p>
