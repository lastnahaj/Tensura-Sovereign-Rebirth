<h2><span class="mw-headline" id="Interactions">Interactions</span></h2>
<p>A named Armorsaurus can be equipped with a saddle and saddlebags using a <span class="nowrap"><span class="sprite-file"><a href="../../items/monster-saddle/" title="Monster Saddle"></a></span> <a href="../../items/monster-saddle/" title="Monster Saddle"><span class="sprite-text">Monster Saddle</span></a></span> and a <a class="external text" href="https://minecraft.wiki/w/Chest" rel="nofollow">Chest</a>. Allowing it to be ridden, the storage is equivalent to two chests.
Using the mount ability key (Default R) causes the Armorsaurus to turn and make a tail swipe. When ridden, the Armorsaurus causes block destruction dependent on where the rider is looking. If looking upwards, moving forwards will break blocks in a upwards staircase, looking downwards, the opposite. Broken blocks are placed in the saddlebags, if the saddlebags are full, or there are no saddlebags, drops will be placed on the ground. Block destruction can be disabled through the mobGreifing gamerule.
</p>
