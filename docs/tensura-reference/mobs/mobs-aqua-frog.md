</p>
<ul><li><ul><li>Being named by a Majin will change its alignment to Majin</li></ul></li></ul>

<h2><span class="mw-headline" id="Special_Skins">Special Skins</span></h2>
<p>Naming an aqua frog "Kermit" (case sensitive) changes the appearance of the Aqua Frog to one with green skin, as well as larger, pale eyes. The skin is a reference to <a class="external text" href="https://en.wikipedia.org/wiki/Kermit_the_Frog" rel="nofollow">Kermit the Frog</a>.
</p>
