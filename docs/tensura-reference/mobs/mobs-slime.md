<h2><span class="mw-headline" id="Info">Info</span></h2>
<p>Deals Corrosion damage <b>(BUT NOT CORROSION EFFECT)</b> , so if you have <a href="../../resistances/corrosion-resistance/" title="Corrosion Resistance">Corrosion Resistance</a> or <a href="../../resistances/corrosion-nullification/" title="Corrosion Nullification">Nullification</a> you can be immune to slime damage.
</p><p>This can also be used to obtain Corrosion Resistance (needs to be 15+ damage).
</p><p>There is a 1/1000 chance that instead of a slime, a <a href="../../bosses/mobs-supermassive-slime/" title="Mobs/Supermassive Slime">Supermassive Slime</a> spawns
</p><p>One can use an empty bucket on a slime to get a <span class="nowrap"><span class="sprite-file"><a href="../../items/items-misc-bucket-of-slime/" title="Bucket of Slime"></a></span> <a class="mw-redirect" href="../../items/items-misc-bucket-of-slime/" title="Bucket of Slime"><span class="sprite-text">Bucket of Slime</span></a></span>
</p><p>Slime mobs takes 50% of the input Physical damage (doesn't stack with [Physical Resistance/Nullification]). (Configurable)
</p>
<h2><span class="mw-headline" id="Skill_obtainment">Skill obtainment</span></h2>
<p>Upon killing 500 slimes, a person can acquire <a href="../../skills/common/self-regeneration/" title="Self Regeneration">Self Regeneration</a>.
</p>
