<p class="reference-eyebrow">At a glance</p>
<p>Lizardmen can only spawn in a Lizardman Village and cannot spawn outside a village. Upon naming, it will evolve into Dragonewt and gain the ability to fly. Lizardmen can trade, but will only restock if they sleep and wake up naturally.</p>

Lizardmen can trade, but will only restock if they sleep and wake up naturally.
</p>
