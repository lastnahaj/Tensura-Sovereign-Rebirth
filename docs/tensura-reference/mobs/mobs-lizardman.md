<p><br/>
Lizardmen can only spawn in a <a href="../../structures/structures-lizardman-village/" title="Structures/Lizardman Village">Lizardman Village</a> and cannot spawn outside a village. Upon naming, it will evolve into Dragonewt and gain the ability to fly.<br/>
Lizardmen can trade, but will only restock if they sleep and wake up naturally.
</p>
