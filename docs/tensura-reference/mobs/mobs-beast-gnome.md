<p><br/>
A medium spirit of earth, can be summoned using <a href="../../magic/summon-medium-elemental/" title="Summon Medium Elemental">Summon Medium Elemental</a>
</p>

<h2><span class="mw-headline" id="Spawn">Spawn</span></h2>
<p>Will not naturally spawn with Majin alignment.
</p>
<ul><li><ul><li>Being named by a Majin will change its alignment to Majin</li></ul></li></ul>
<h2><span class="mw-headline" id="Drops">Drops</span></h2>
<ul><li>0 - 1 <span class="nowrap"><span class="sprite-file"><a href="../../items/items-misc-elemental-shard-earth/" title="Elemental Shard (Earth)"></a></span> <a class="mw-redirect" href="../../items/items-misc-elemental-shard-earth/" title="Elemental Shard (Earth)"><span class="sprite-text">Elemental Shard (Earth)</span></a></span>, 25% chance</li>
<li>0 - 1 <span class="nowrap"><span class="sprite-file"><a href="../../items/elemental-essence/" title="Elemental Essence"></a></span> <a href="../../items/elemental-essence/" title="Elemental Essence"><span class="sprite-text">Elemental Essence</span></a></span>, 10% chance</li></ul>
<h2><span class="mw-headline" id="Feeding">Feeding</span></h2>
<p>A Beast Gnome can be fed any kind of magic crystal, restoring 5 health per crystal.
</p>
<h2><span class="mw-headline" id="Additional_Features">Additional Features</span></h2>
<p>Right clicking a Beast Gnome with an empty hand allows the user to Ride it. If right clicked with a non empty hand, the beast gnome shrinks in size, reduced to half a block in height. If right clicked with an empty hand in this state, the Beast Gnome rides the head of the player. You can command the Beast Gnome as normal by right clicking it while crouched.
</p>
