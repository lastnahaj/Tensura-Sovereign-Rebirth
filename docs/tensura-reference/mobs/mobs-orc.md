<h2><span class="mw-headline" id="Royal_Orc">Royal Orc</span></h2>
<h3><span class="mw-headline" id="Info_2">Info</span></h3>
<p>This is a rare variant of a regular orc, which can be bred to get more royal orcs. <br/>
</p>
<h4><span class="mw-headline" id="Gelmud_Method">Gelmud Method</span></h4>
<p>If you feed a Royal Orc 10 <a href="../../items/royal-blood/" title="Royal Blood">Royal Blood</a> that:
</p>
<ul><li>has 80k ep</li>
<li>has the <a href="../../skills/common/self-regeneration/" title="Self Regeneration">Self Regeneration</a> skill</li>
<li>is <b>not tamed/named</b></li></ul>
<p>The Royal Orc will evolve into an <a href="../../bosses/mobs-orc-lord/" title="Mobs/Orc Lord">Orc Lord</a>. This Orc Lord will be <b>Neutral</b> towards you. Only some Royal Orcs have the <a href="../../skills/common/self-regeneration/" title="Self Regeneration">Self Regeneration</a> skill, so not all are able to be evolved.
</p>
<h3><span class="mw-headline" id="Drops_2">Drops</span></h3>
