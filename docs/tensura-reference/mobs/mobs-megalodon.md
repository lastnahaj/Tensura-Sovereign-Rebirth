<h2><span class="mw-headline" id="Interactions">Interactions</span></h2>
<p>A named megalodon can be equipped with a saddle and saddlebags using a <span class="nowrap"><span class="sprite-file"><a href="../../items/monster-saddle/" title="Monster Saddle"></a></span> <a href="../../items/monster-saddle/" title="Monster Saddle"><span class="sprite-text">Monster Saddle</span></a></span> and a <a class="external text" href="https://minecraft.wiki/w/Chest" rel="nofollow">Chest</a>. Allowing the Megalodon to be flown, ascending with space and descending with the Mount Decend key (Default V) The storage is equivalent to two chests.
Using the mount ability key (Default R) causes the Megalodon to rush foward, similar to a trident's riptide. If the megalodon flies into blocks they may get destroyed as a result, placing the dropped contents inside the saddle bags. If the saddlebags are full, or there are no saddlebags, common blocks have their drops deleted (stone, dirt) while uncommon blocks drop on the ground (raw ore, amethyst, etc.). Notable blocks that this can break through while retaining drops are obsidian and Magic Ore, presenting a way to easily mine these materials. The Megalodon's block destruction can be disabled through the mobGreifing gamerule.
</p>
