<section class="skill-obtainment" aria-labelledby="how-to-obtain"><p class="reference-eyebrow">Battlewill · Pinned pack inventory</p><h2 id="how-to-obtain">How to obtain</h2><p><strong>Random manual route:</strong> Use a <a href="../items-misc-battlewill-manual/">Battlewill Manual</a>. This ability is one of the <strong>16 configured random results</strong>; a manual does not let you choose it.</p><p>The manual can be consumed without adding a new ability, including when its result is already known. A bound manual is a separate case: it uses its stored ability instead of this random pool.</p><p class="skill-evidence-note">Checked against Tensura 2.0.1.2 and the tracked 1.21.1 configuration.
