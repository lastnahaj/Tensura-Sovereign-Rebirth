<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p>Randomly gives one of the many <a class="mw-redirect" href="https://tensura.wiki.gg/wiki/Abilities/Battlewills" title="Abilities/Battlewills">battlewill</a> skills. The book can attempt to give you a skill you already know resulting in no skill being learnt and the message "You already had (Battlewill Skill)".
</p><p>Can also be placed inside a <a class="external text" href="https://minecraft.wiki/w/Chiseled_Bookshelf" rel="nofollow">Chiseled Bookshelf</a> (Has no purpose except for decoration)
</p>
