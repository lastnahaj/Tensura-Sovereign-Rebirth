## Where it appears

This is the large dark-portal structure that has both a structure definition and a structure set in Mysticism 2.1.2.

## What this reference confirms

The matching biome tag is `mysticism:is_dark_biome`; the structure uses terrain adaptation that buries part of the template.

The structure, structure set, and applicable biome tag are present in the pinned artifact. Server configuration, pregenerated terrain, or an existing world border can still affect what players encounter.
