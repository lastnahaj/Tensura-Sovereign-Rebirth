## Where it appears

The packaged structure targets the optional common desert tag and Minecraft's desert-village biome tag.

## What this reference confirms

Spacing and separation describe the structure-set placement grid, not a guaranteed distance from spawn or a live-server discovery rate.

The structure, structure set, and applicable biome tag are present in the pinned artifact. Server configuration, pregenerated terrain, or an existing world border can still affect what players encounter.
