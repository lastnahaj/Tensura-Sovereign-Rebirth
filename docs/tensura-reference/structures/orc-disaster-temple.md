## Where it appears

The temple's packaged biome tag contains only the vanilla desert biome.

## What this reference confirms

It is a surface structure with beard-thin terrain adaptation; this page does not infer boss triggers or loot that are not declared in the worldgen data.

The structure, structure set, and applicable biome tag are present in the pinned artifact. Server configuration, pregenerated terrain, or an existing world border can still affect what players encounter.
