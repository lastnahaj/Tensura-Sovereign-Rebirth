<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>When attacking a target with both hands empty (only empty main hand with Creator Mastery):
<ul><li>Remove all barrier points from target</li>
<li>Inflict a debuff on target that makes Skills unable to be activated for 4s</li>
<li>removing all skill status effects(buff/debuff)</li></ul></li></ul>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>(Toggleable with <a class="mw-redirect" href="../../unique/creator/" title="Abilities/Skills/Creator">Creator</a>’s Mastery)
<ul><li>Makes the user immune to <a class="mw-redirect" href="../../../magic/abilities-magics/" title="Magic">Magic</a>, <a class="mw-redirect" href="../abilities-skills/" title="Skills">Skills</a> (this includes Resistances)</li>
<li>Skill Debuffs (mind-control, infinity prison, spatial blockade, magic jamming, etc.)</li>
<li>Battlewill.</li>
<li>When punching a <a class="mw-redirect" href="../../common/ranged-barrier/" title="Abilities/Skills/Ranged Barrier">Ranged Barrier</a>, instantly destroy it.</li></ul></li>
<li>disables skill stealing (even if skill stealing gamerule is off and its considered copying).</li>
<li>Can attack Spiritual Entities</li>
<li>Become immune to spiritual damage and Energy Drain</li></ul>
