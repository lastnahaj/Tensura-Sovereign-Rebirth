<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - Makes learning Battlewills and Magic happen instantly</li>
<li>[Passive - True] - The player earns 2 more mastery points with each usage.</li>
<li>[Passive - In Slot] - The player gets +75 base damage (+150 With Mastery) Can select damage output by holding skill activation and scrolling mouse wheel.</li></ul>
