<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, In-slot] Magic Alteration: While this skill is in solt, it boosts all your magic damage by +10. The user bypasses Magic Jamming, The user degrades Nullifications to Resistances</li>
<li>Passive - Toggle] Gluttonous Witch:</li></ul>
<p>While this skill is toggled on, when exposed to Magic, the user will learn it.
</p>
<ul><li>[Passive - Not Toggled] Enchant - Instant:</li></ul>
<p>The user can instantly cast any mastered spell. When this skill is mastered, the user can instantly cast any spell.
</p>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Spellbook - When shifted used, the user may select one of their known spells and amplify it, when used again while you are not shifting, you begin to cast the spell.</li>
<li>[Active, Press] Absolute Cancel - When used, this ability will nullify any effects on the user, when used on another target it will nullify any effects on the target, when shift used, this will nullify any effects on all nearby targets. When mastered, this will also remove Cook.</li></ul>
