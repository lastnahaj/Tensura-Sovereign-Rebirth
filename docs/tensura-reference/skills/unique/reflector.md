<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - In Slot] - Whenever the user takes damage, add an equal amount of Echo Points as the amount of damage, the skill must be in Skill Slots.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <b>Echo Reflection</b>: Consumes all of the player's Echo Points and unleash an electric projectile that deals damage equal to their Echo Points x3 (x5 with Mastery). Scroll mouse while sneak holding down this mode to change the power output percentage.</li></ul>
<ul><li>[Active - Hold] - <b>Echo Counter</b>: While held down, the user cannot move or attack if not mastered, but the next attack they take will be canceled and reflect that damage back to the attacker. If the attack is not Projectile, the damage is reflected directly back to the attacker with x2.5 force. If the attack type is Projectile, the projectile will go back to its owner with x2 speed and x2.5 damage if it’s a Magic Projectile. Cooldown 5s.</li></ul>
