<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Deal - When pressed, you can start a bargain to create a deal. There are various different types of bargains to be made. For EP, For Skills, for a Skill Toggle, Skill Sub-mode.
<ul><li>The user cannot break the contract, but if they contracted target does, the user gains all of the benefits and no longer needs to uphold the bargain.</li></ul></li></ul>
