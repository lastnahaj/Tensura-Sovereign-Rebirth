<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Anti-Skill">Anti-Skill</span></h3>
<ul><li><a class="mw-redirect" href="../../other/anti-skill/" title="Abilities/Skills/Anti-Skill"><b>Anti-Skill</b></a> is a skill only accessible through the Creation subskill. Anti-Skill makes the user immune to Magic, Skills, and Battlewill. When punching a Ranged Barrier, instantly destroy it. When attacking a target when both hand empty (only empty main hand with Creator’s Mastery), remove all barrier points from target and inflict a debuff on target that makes Skills unable to be activated for 4s. (Toggleable with Creators' Mastery)</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <a class="mw-redirect" href="../../extra/analytical-appraisal/" title="Abilities/Skills/Analytical Appraisal"><b>Analytical Appraisal</b></a>: Analysis Level 1 (2 with Mastery), distance 5 blocks (10 with Mastery), If a target has greater than 2x (4x with Mastery) the player's EP, then only its base stats are shown (Name, HP, SHP, Armor).</li></ul>
<ul><li>[Active - Press] - <b>Skill Creation</b>: When used, allows the player to select one Unique Skill or Anti-Skill, which is then granted to the user for 20 minutes (1 MC day). Cannot create the same skill twice in a row without Mastery. All skills gained via a copy/plunder skill obtained through Creator are considered temporary, and will be removed once the copy/plunder skill is removed</li></ul>
<h3><span class="mw-headline" id="Notes">Notes</span></h3>
<ul><li>Any skill created trough Creator that would grant a/multiple secondary skills, will not grant said skills</li></ul>
