<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, Toggle] Dragon's Claw - The user gains +1 Attack Damage per 100 Mastery. (1,000 Mastery by default). This becomes 2 when mastered.</li>
<li>[Passive, In-slot] Cut Through - The user bypasses Resistances and Nullifications.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Dragon Claw - This is a slashing attack that cannot be preformed with an item in hand. It deals the user's Attack Damage x2 as damage and has a 7 block + reach range as damage. This will destroy blocks if gamerule isn't on.</li></ul>
