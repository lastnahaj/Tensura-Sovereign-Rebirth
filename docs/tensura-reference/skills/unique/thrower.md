<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - <b>Homing Projectile</b>: Item thrown by user will be homing toward where the user’s looking at or lock on into a target and chase them (max range 50-blocks).</li>
<li>[Passive - True] - User deals much more damage using Kunai, Spear &amp; Trident instead of their default damage.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <b>Throw</b>: When activated, consumes the currently held item and creates a projectile with its texture as a model.
<ul><li>The projectile deals 50 (100 if mastery, damage boosted with <a class="mw-redirect" href="../../extra/gravity-domination/" title="Abilities/Skills/Gravity Domination">Gravity Domination</a>/<a class="mw-redirect" href="../../extra/gravity-manipulation/" title="Abilities/Skills/Gravity Manipulation">Manipulation</a> toggled by x3/x2) damage,</li>
<li>if the item is a weapon, then it deals its normal damage too.</li>
<li>If the thrown item is a block breaking tool, it will break blocks based on the broken block and tool level(Max breakable blocks in a row is 10,configurable).</li>
<li>Items with elemental cores will deal elemental damage as well(Not boosted by manipulations or dominations).</li>
<li>If used with an empty hand, creates an air projectile that deals 30 damage (50 with mastery).</li>
<li>If activated while looking at an enemy within 2 blocks of the player, flings them 15 blocks instead (further with <a class="mw-redirect" href="../../extra/gravity-manipulation/" title="Abilities/Skills/Gravity Manipulation">Gravity Manipulation</a>/<a class="mw-redirect" href="../../extra/gravity-domination/" title="Abilities/Skills/Gravity Domination">Domination</a> toggled).</li>
<li>Thrown item's momentum is boosted by the players momentum. Costs 40 MP each usage.</li></ul></li></ul>
<h3><span class="mw-headline" id="Mastery">Mastery</span></h3>
<ul><li>Thrown <i>items</i> (not arrows, tridents, kunais, ...) have Loyalty effect
<ul><li>If the player has <a class="mw-redirect" href="../../extra/gravity-manipulation/" title="Abilities/Skills/Gravity Manipulation">Gravity Manipulation</a>/<a class="mw-redirect" href="../../extra/gravity-domination/" title="Abilities/Skills/Gravity Domination">Domination</a> there is a higher return speed</li></ul></li></ul>
