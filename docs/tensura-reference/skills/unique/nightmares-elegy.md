<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h2><span class="mw-headline" id="Passive">Passive</span></h2>
<ul><li>[Passive, True] Spatial Barriers:
<ul><li>The user learns Barrier, Spatial Manipulation, Spatial Motion</li></ul></li></ul>
<h2><span class="mw-headline" id="Actives">Actives</span></h2>
<ul><li>[Active, In-slot] Barrier Refinement:
<ul><li>While this mode is in-slot, the user doubles all Barrier Points they gain.</li></ul></li></ul>
<ul><li>[Active, Press] Counter Barrier:
<ul><li>The user can use this mode on any projectiles, instantly destroying them. The cost 100 Barrier Points to use MP.</li></ul></li></ul>
<ul><li>[Active, Press] Stability:
<ul><li>The user can remove all of their Barrier Points to restore their MP and HP based off the Barrier Points.
<ul><li>1 Barrier Point = 100 MP</li>
<li>1 Barrier Point = 5 HP</li></ul></li></ul></li></ul>
