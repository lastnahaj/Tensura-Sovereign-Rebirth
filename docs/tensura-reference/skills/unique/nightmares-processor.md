<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Multi-Threading- User is capable of running/chanting 2 abilities simultaneously. (This is moved to 3 on mastery.)</li>
<li>[Passive, True] Rapid Access Memory - Using a spell again within a 5 seconds or less window of using it while "Allocate" is enabled will instant cast it. {RAM is cleared every 5 seconds, so there is no guarantee you will have a full 5 seconds to use it}</li>
<li>[Passive, Toggled] Thought Acceleration - Divide casting time by 2 in most cases and increase invulnerability frames from dodging by 1.</li>
<li>On mastery, casting time is decreased by that same factor for each 'Thread' you put into it along with I-Frames being increased.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press/Toggle] Allocate -Using this allows you to allocate you extra Thread(s) into using 1 ability, effectively turning off the ability to multi-cast. Use the ability normally to activate and shift use it to deactivate it. (On mastery, when not using any active abilities, they will be allocated into thought acceleration.)</li>
<li>[Active, Press] Overclock - Requires Mastery - Increase strength of all of this skill's capabilities by thirty percent for 40 seconds, disables the entire skill afterwards for 5 Minutes so it can 'cool down'. (Having Heat resistance allows you to shift use it for the same amount of time and same cooldown but with a fifty percent boost, or use it normally for a thirty percent boost for 1 minute and disabling the skill for 3 minutes and 20 seconds. Heat nullification allows the 50% with the lower cooldown and higher time.)</li></ul>
