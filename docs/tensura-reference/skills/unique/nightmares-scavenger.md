<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Hold] Evil Eater - This is a predation ability. It is similar to Gluttony's Predator with the sole exception of it's ability to consume item's as well.</li>
<li>[Active, Press] Stomach - This is a storage ability which houses stacks of 98. It has 24 pages.</li>
<li>[Active, Press] Devour - The user can devour the item in their hand. This gives them 10% (25% when mastered) of its EP. This will also give the user skills related to the engravements on the item.</li></ul>
