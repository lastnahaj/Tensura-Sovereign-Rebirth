<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - <b>Parallel Processing</b>: Increases the amount of Learned Points and Mastery Points gained when learning/using Skills, Magic, Battlewill, and Arts by 9 (10 Total).</li></ul>
<ul><li>[Passive - Toggle] - <a class="mw-redirect" href="../../extra/chant-annulment/" title="Abilities/Skills/Chant Annulment"><b>Chant Annulment</b></a>: For Mastered Magic, completely fills up the Magic Circle's MP meter instantly.</li></ul>
<ul><li>[Passive - Toggle] - <a class="mw-redirect" href="../../extra/thought-acceleration/" title="Abilities/Skills/Thought Acceleration"><b>Thought Acceleration</b></a></li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <a class="mw-redirect" href="../../extra/analytical-appraisal/" title="Abilities/Skills/Analytical Appraisal"><b>Analytical Appraisal</b></a>: Analysis Level 2, distance 20 blocks (30 with Mastery), If a target has greater than 5x (10x with Mastery) the player's EP, then only its base stats are shown (Name, HP, SHP, Armor).</li></ul>
<ul><li>[Active] - <b>Analysis</b>: When used while looking at a mob, copies 1 of the Magic, and Skills (Except Unique Skills &amp; Resistances) of a target. Can copy from up to 20 blocks away while in line of sight of entity or magic circle and won't work on any spirit related magic. Ineffective against Ultimate Skill Users. 25% Chance at Success, which raises to 50% with Mastery - 10s cooldown (5s if failed).</li></ul>
<ul><li>[Active] - <b>Refining</b>: Opens a GUI that can be used to craft things, brew potions and process magic ore</li></ul>
<ul><li><ul><li>Crafting tab: Works like a normal crafting table. Put an item in the replication slot on the left, to craft that item like a smithing bench without the need of Schematics, the user can replicate that item just by having the materials in the crafting grid. Has a button on the right to auto craft desired items in each 5 seconds.</li></ul></li></ul>
<ul><li><ul><li>Refining tab:  Brewing any potions like brewing stand but all at once in 5 seconds. If a <span class="nowrap"><span class="sprite-file"><a href="../../../items/hipokute-grass/" title="Hipokute Grass"></a></span> <a href="../../../items/hipokute-grass/" title="Hipokute Grass"><span class="sprite-text">Hipokute Grass</span></a></span> is placed into a slot with any bottle, it "brews" into a <span class="nowrap"><span class="sprite-file"><a href="../../../items/high-potion/" title="High Potion"></a></span> <a href="../../../items/high-potion/" title="High Potion"><span class="sprite-text">High Potion</span></a></span>. If a <span class="nowrap"><span class="sprite-file"><a href="../../../items/hipokute-flower/" title="Hipokute Flower"></a></span> <a href="../../../items/hipokute-flower/" title="Hipokute Flower"><span class="sprite-text">Hipokute Flower</span></a></span> is placed into a slot with any bottle,, it brews into a <span class="nowrap"><span class="sprite-file"><a href="../../../items/full-potion/" title="Full Potion"></a></span> <a href="../../../items/full-potion/" title="Full Potion"><span class="sprite-text">Full Potion</span></a></span>. If a <span class="nowrap"><span class="sprite-file"><a href="../../../magic/magic-ore-shard/" title="Magic Ore Shard"></a></span> <a href="../../../magic/magic-ore-shard/" title="Magic Ore Shard"><span class="sprite-text">Magic Ore</span></a></span> is placed into a slot, "brews" into 2 <span class="nowrap"><span class="sprite-file"><a href="../../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"></a></span> <a href="../../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"><span class="sprite-text">Pure Magisteel Nuggets</span></a></span>.</li></ul></li></ul>

## In Tensura: Sovereign Rebirth

<span class="tsr-status">Under Validation</span>

Great Sage 0.0.5 is installed and its client/common configuration is tracked. The possession requirement is a world gamerule; automatic first-world enforcement remains a release gate, so the wiki does not yet present it as universally enforced.
