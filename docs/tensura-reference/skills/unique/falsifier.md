<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<p>[Passive - Toggle] Makes the player able to see through illusions and invisible targets
</p>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] <b>Presence Concealment</b>: When activated, makes mobs unable to register the player for 120 seconds. Costs 200 MP.</li></ul>
<ul><li>[Active - Press] <b>Illusion</b>: When activated, open a GUI that enables the player to choose any fake item to wear on each armor and hand slot.</li></ul>
<ul><li>[Active - Hold] <b>Fake Death</b> : When held down, reduce the speed by 40% (20% with Mastery). While this mode is held down (maximum hold time is 30 seconds), if the user takes any type of damage, spawn a new body then instant kill it with the same type of damage and send a fake death message to every player online. At the same time, reduce the incoming damage by half for the user and put the user into Presence Concealment, and stay in concealment till release or max hold time is reached - 10s cooldown (5s with Mastery)</li></ul>
