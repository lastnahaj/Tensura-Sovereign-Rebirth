<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Pyromaniac - The user gains all of the Flame-Type Aspectual Magics.</li>
<li>[Passive, Toggled] Paradox Flame - All of the user's Flame Magics become White. They apply the Freeze Effect when dealing Fire Damage.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] After World - The user creates a virtual space around them which makes all of their Flame Magics deal Spiritual Damage as well. Anything killed inside of the After World will give the user Soul Points. The user gains 1.5x EP Regeneration inside of After World for every 1,000 Souls they possess.</li>
<li>[Active, Toggle] White Flame - The user coats themselves in ultra-white hot flames. These flames apply Freezing Burn on hit. Entities with Spiritual Attack Nullification and Thermal Fluctuation Nullification are able to ignore this effect.</li></ul>
