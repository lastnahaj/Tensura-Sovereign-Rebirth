<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active,Press] Skill Evolution - When Pressed, the user opens up the Skill Designer GUI which will contain the various Skill Evolution options. Each Evolution option has various MP costs per. Skill Evolutions MP cost to attempt is offten equal to the Total MP of possible Skills, sometimes x2.</li>
<li>[Active, Press] Recycle - When Pressed, the user opens the Recycle GUI. Any Skill the users owns, can be "Recycled" here. Recycling the skill will grant you its Magicule Cost, while there is a 5% Chance (10% Chance when mastered) to gain 10% (20% when mastered) more MP than the skills original cost.</li>
<li>[Active, Held] Magicule Furnace - When held, the user begins to generate Magicules, restoring 3% (5% when mastered). The user can generate current Magicules up to 225% of the user's Max Magicules.</li>
<li>[Active, Press] Apocrypha - When pressed, the user toggles on the Apocrypha state, as the user begins to lose Magicules at 8% (6% when mastered) every two seconds. The user boosts their Attack Damage by 10 (30 when mastered) and armor by 15 (30 when mastered). While Apocrypha is active, the user bypasses Physical Attack Nullification.</li>
<li>[Active, Held] Divine Darkness - When held, the user fires a beam that deals 50 Holy and 50 Darkness Damage. (100 when mastered) a second and cost 3.5% MP per second fire.</li></ul>
