<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, Toggle] Ultra Instinct</li></ul>
<h3><span class="mw-headline" id="Actives">Actives</span></h3>
<ul><li>[Active, Press] Tribe Summon - The user can create allied Direwolves. This summons 1-3 (3-6 when mastered) that are loyal to the user, and house no name until the skill is mastered. Only 12 Direwolves can exist from this skill at a time.</li></ul>
<p>Once the skill is mastered, the user can use the command /trnightmare pack name to name the pack of wolves.
</p>
<ul><li>[Active, Hold] Tribe Regeneration  - The user begins to regenerate themselves at a similar speed and cost to Ultraspeed Regeneration, when used while at full HP, it begins to heal all nearby Direwolves under the Pack Name.</li>
<li>[Active, Press] Assimilation - The user can user Assimilation to merge with a subordinate, or if no subordinate is looked at, a member of their pack. This increases the user's stats by the stats of their Subordinate, and they gain access to all of their Skills while Assimilated.</li>
<li>[Active, Press] Will Manipulation - The user can press this to send a command to the entire pack. Scroll to change commands:</li></ul>
<p>Neutral/passive/aggressive/protect
</p><p>Note: Aggressive targetting: Attack if Entitiy is
1.Not allied
2.Over 10k EP
</p>
