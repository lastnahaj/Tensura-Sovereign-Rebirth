<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, In-slot] Castle Guard:
<ul><li>While this mode is in slot, the user is rendered immune to all forms of skills, magic and battlewills. The user cannot use skills, magic or battlewills while this mode is active. The user suffers the same penalty, as they cannot use any skills, magic or battlewills; however, they can attack and use Haki. This mode can only be active for a minute. The user needs at least 3 subordinates to make Castle Guard work.</li></ul></li></ul>
<p>(Castle guard can be bypassed by Nova Break)
</p>
<ul><li>[Active, Held] Angel Knight:
<ul><li>The user presses and holds this ability for 30 seconds (10 when mastered) to summon an Angel Knight (3 when mastered). This Angel Knight is a subordinate who can help them.</li></ul></li></ul>
<p>(The Angel Knight has 50 HP (200 when mastered).) They have access to Holy Attack Resistance, Sleep Mist, and Solar Rain.)
</p>
<ul><li>[Active, Held] King's Authority:
<ul><li>The user holds this ability for 60 seconds. (30 when mastered) to make a target a temporary subordinate. If the target's naming is on, this allows the user to name the subordinate without paying the MP cost. The user does, however, need to pay the EP of the target to subordinate them.</li></ul></li></ul>
<p>(King's authority needs 30% EP or more to work)
</p>
