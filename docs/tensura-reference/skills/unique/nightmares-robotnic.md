<ul><li>[Active, Press] Deconstruct: Data - Open a menu containing the user‘s entire list of skills, if skill is selected, add 1/2 of the skill‘s obtainment cost to the user‘s maximum MP, and 1/2 to the skill.</li>
<li>[Active, Press] Deconstruct: Object - Delete the item in the user‘s main hand and if it had an EP value, add half of it to the user‘s maximum AP and the skill‘s storedMP. 30 second cooldown.</li></ul>
