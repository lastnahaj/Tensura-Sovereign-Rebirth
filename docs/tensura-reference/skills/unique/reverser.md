<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <b>Inverted Fusion [Buff]</b>: When activated, removes all negative status effects (besides some exception like <a href="../../../core-mechanics/effects-magicule-poison/" title="Effects/Magicule Poison">Magicule Poisoning</a>) from the player if looking at nothing or the looked at mob/player and grants buffs based on the status effect removed (if applicable). <a href="../../../core-mechanics/effects-paralysis/" title="Effects/Paralysis">Paralysis</a>, <a class="external text" href="https://minecraft.wiki/w/Slowness" rel="nofollow">Slowness</a> = <a class="external text" href="https://minecraft.wiki/w/Speed" rel="nofollow">Speed</a>; <a class="external text" href="https://minecraft.wiki/w/Poison" rel="nofollow">Poison</a>, <a href="../../../core-mechanics/effects-corrosion/" title="Effects/Corrosion">Corrosion</a>, <a class="external text" href="https://minecraft.wiki/w/Wither_(effect)" rel="nofollow">Wither</a> = <a class="external text" href="https://minecraft.wiki/w/Regeneration" rel="nofollow">Regeneration</a>; <a href="../../../core-mechanics/effects-burden/" title="Effects/Burden">Burden</a> = <a class="external text" href="https://minecraft.wiki/w/Slow_Falling" rel="nofollow">Slow Falling</a> + <a class="external text" href="https://minecraft.wiki/w/Speed" rel="nofollow">Speed</a> + <a class="external text" href="https://minecraft.wiki/w/Jump_Boost" rel="nofollow">Jump Boost</a>; <a href="../../../core-mechanics/effects-fragility/" title="Effects/Fragility">Fragility</a> = <a class="external text" href="https://minecraft.wiki/w/Resistance" rel="nofollow">Resistance</a>; <a class="external text" href="https://minecraft.wiki/w/Mining_Fatigue" rel="nofollow">Mining Fatigue</a> = <a class="external text" href="https://minecraft.wiki/w/Haste" rel="nofollow">Haste</a>, <a class="external text" href="https://minecraft.wiki/w/Hunger_(effect)" rel="nofollow">Hunger</a> = <a class="external text" href="https://minecraft.wiki/w/Saturation" rel="nofollow">Saturation</a>; <a class="external text" href="https://minecraft.wiki/w/Bad_Luck" rel="nofollow">Bad Luck</a> = <a class="external text" href="https://minecraft.wiki/w/Luck" rel="nofollow">Luck</a>, <a class="external text" href="https://minecraft.wiki/w/Weakness" rel="nofollow">Weakness</a> = <a class="external text" href="https://minecraft.wiki/w/Strength" rel="nofollow">Strength</a>, <a class="external text" href="https://minecraft.wiki/w/Night_Vision%7C" rel="nofollow">Night Vision</a> = <a class="external text" href="https://minecraft.wiki/w/Blindness%7C" rel="nofollow">Blindness</a>/<a class="external text" href="https://minecraft.wiki/w/Darkness%7C" rel="nofollow">Darkness</a>, <a class="external text" href="https://minecraft.wiki/w/Invisibility%7C" rel="nofollow">Invisibility</a> = <a class="external text" href="https://minecraft.wiki/w/Glowing%7C" rel="nofollow">Glowing</a> etc. It can also turn Curses from gear into Blessings when the skill is mastered or completely erase those curses if they don't have a blessing counterpart</li>
<li>[Active - Press] - <b>Inverted Fusion [Debuff]</b>: Invert the possible reverse Above
<ul><li>Inverted fusion becomes toggleable with mastery. Once toggled, it will automatically inverse any negative effect applied.</li>
<li>Reversing now respects the ratio of reversed effects (for example, Resistance = Fragility II).</li>
<li>Can reverse effects on potion items on entities with mastery.</li></ul></li>
<li>[Active - Press] - <b>Alignment Reverse</b>: If the player is a <a href="../../../core-mechanics/races-alignment/" title="Races/Alignment">Majin</a>, <a href="../../../core-mechanics/races-alignment/" title="Races/Alignment"> Holy</a> or <a href="../../../core-mechanics/races-awakening/#True_Hero" title="Races/Awakening">True Hero(TH)</a>, sets Alignment to Chaos (Which can be seen as it changes the Race name color to Red). When the alignment is set to Chaos, the player can become <a href="../../../core-mechanics/races-awakening/#True_Hero" title="Races/Awakening">TH</a> when their race is <a class="mw-redirect" href="../../../core-mechanics/races-alignment/" title="Races/Majin">Majin</a>. Chaos-aligned beings are no longer affected by <a href="../../../core-mechanics/engravings/#Holy_Coat" title="Engravings">Holy Coat</a>, and no longer take extra damage from <a href="../../../bosses/mobs-charybdis/" title="Mobs/Charybdis">Charybdis's</a> Wicked Light Ray.  <b>With Mastery, you can set the alignment of other players or mobs to Chaos.</b></li></ul>
