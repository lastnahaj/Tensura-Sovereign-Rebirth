### Toggle passive

Adds **0.19** to the learning and mastery gain attributes in the pinned configuration. This is an attribute modifier, not 19 mastery points awarded per use. The skill also provides Chant Annulment for mastered magic.

### Mode 1 — Magic Chant

Spend **10 XP levels** to learn one random magic you do not know.

### Mode 2 — Study

Look at a magic spell's incantation circle to learn and master that magic instantly.

### Mode 3 — Create Tome

Open a menu, insert a book, and select any magic you know to create its magic tome. Creating a tome costs **5 XP levels** in the pinned configuration.

**Awakening:** [The Timeless Mage](../ultimate/the-timeless-mage.md)
