<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[ Passive - In Slot ] - Copy: The user can copy an ability's specific mode after being hit or affected by it when [Pride]'s Copy Mode is in slot. Without mastery, it will only be able to copy attacks, such as <a href="../absolute-severance/" title="Absolute Severance">Absolute Severance</a>. Once mastered, [Pride] will be able to copy abilities when inflicted with status effects like <a class="mw-redirect" href="../infinity-prison/" title="Abilities/Skills/Infinity Prison">Infinity Prison</a>'s Imprison or <a href="../healer/" title="Healer">Healer</a>'s Infection. Note that [Pride] won't be able to copy any spirit related magic</li></ul>
<ul><li><ul><li>[Pride]'s Mastery gain is based on the copied ability's cost, (Example: you get 1 point per 2500 MP cost, so if the ability costs 10K to acquire, you get 4 mastery points) while cooldown is 5s. On a failed copy, [Pride] will only gain 10% of the mastery it would've gained on a successful copying of the ability, but the cooldown is similarly reduced to 10%.</li></ul></li></ul>
<ul><li><ul><li>Once a mode is successfully copied, the user will pay the whole ability's obtainment cost and [Pride] will go on cooldown. The copied mode will be added as a new Mode for [Pride] (If this mode requires learning, it will be instantly learnt once acquired). As this is a new mode on [Pride] itself, the copied skill's passive features won't be usable and a mode may be unusable if it depends on said passive features or other modes of the ability.</li></ul></li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[ Active - Press ] - <b>Copy</b> : Opens a new GUI that allows the user to quickly equip or remove copied ability modes.</li></ul>
