<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - Grants a boost effect similar to the riptide enchantment that can only be used underwater. Hitting an enemy during riptide effect will deal damage equal to players attack damage. It’s activated by the user and costs 2MP to activate</li></ul>
