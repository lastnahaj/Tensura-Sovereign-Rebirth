<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - Grants the user <a href="../../../core-mechanics/effects-strengthen/" title="Effects/Strengthen">Strengthen</a> for 60 seconds and costs 30 MP. With Mastery, Increase to <a href="../../../core-mechanics/effects-strengthen/" title="Effects/Strengthen">Strengthen</a> II, lasts 120 seconds, and becomes toggleable but will only grant <a href="../../../core-mechanics/effects-strengthen/" title="Effects/Strengthen">Strengthen</a> this way.
<ul><li>This skill gains mastery passively while its actived, and can be pressed again to deactivate it</li></ul></li></ul>
