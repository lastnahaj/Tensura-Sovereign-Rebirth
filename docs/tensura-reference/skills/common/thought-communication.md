<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - <b>Movement Behaviour</b>: Activate when looking at an entity in a 30 block radius.
<ul><li>If it’s a subordinate, cycle through stay/follow/wander modes.</li>
<li>If it’s a non-ally target, all subordinates in the range of a 30x30x30 radius around the user will start to attack that target.</li>
<li>If shifted when activating, cycle through stay/follow/wander modes of all subordinates in a 30x30x30 radius.
<ul><li>Wander Mode: the subordinate will wander 50 blocks around the position where it is set to Wander.</li></ul></li></ul></li></ul>
<ul><li>[Active - Press] - <b>Targeting Behavior [Require Mastery]</b>:
<ul><li>If activated when looking at a subordinate in a 30 block radius, if that’s a subordinate, cycle through neutral/passive/aggressive/protect modes.</li>
<li>If shifted when activating, cycle through neutral / passive / aggressive / protect modes of all subordinates in a 30x30x30 radius.
<ul><li>Neutral Mode: The subordinate will defend when attacked, and when the owner is attacked or attacks.</li>
<li>Passive Mode: It will not target anything even if hit.</li>
<li>Aggressive Mode: The subordinate will target everything that is not an ally.</li>
<li>Protect Mode: It will target everything that is targeting its owner or ally.</li></ul></li></ul></li></ul>
