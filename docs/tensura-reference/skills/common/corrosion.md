<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - In Slot] - Inflicts <a href="../../../core-mechanics/effects-corrosion/" title="Effects/Corrosion">Corrosion</a> onto target [Togglable if mastered].</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - Turns meat items in hand into rotten flesh when pressing ability button.</li></ul>
<p>Tip: you can easily master this skill by turning meat items into rotten flesh<br/> <i>(1 meat item = 1% mastery)</i>
</p>
