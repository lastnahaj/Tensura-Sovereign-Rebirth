<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Information Body:
<ul><li>The user cannot exist without a host. They begin to lose 1% of their MP every 5 seconds when outside of a Body or if they're not bound to their host. The user gains +14 Mastery and Learn Speed.</li></ul></li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Hijack Or Host:
<ul><li>The user can use this ability to forcefully hijack near-dead targets to act as their host, however this only works for so long. (Randomly gives a time between 5 minutes and 5 hours on the possession of the body, and will warn you 2 minutes, 1 minute, 30 seconds, 10 seconds and 5 seconds before the body collapses.</li>
<li>When shift used, this is instead "Host" which allows the person to enter a spectator-like state, attached to a player that is they're allied too. They're unable to use any skills outside of Divine Wisdom Core or their Ego Boosted Skill while in this mode.
<ul><li>The hosted player gains +14 Mastery and Learn Speed, as well as +0.4 Cast Speed.</li></ul></li></ul></li></ul>
<ul><li>[Active, Press] Ego Boost:
<ul><li>The user is able to open a menu to list all of their skills, the user injects their ego into the skill, and places it under Ego Boost, reducing all of its cooldowns and magicule costs by 50%. The user can only connect their Ego to one skill the Host has, and this benefit is only active while they're connected to the host. If the host loses the skill, or the skill is evolved, the user of this skill can select a new skill to Ego Boost.</li></ul></li></ul>
