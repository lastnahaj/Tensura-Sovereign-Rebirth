<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active] Giantification: When activated, increases player height by 3 blocks and grants +6 Attack Damage (Speed, Jump Strength and Attack/Mining reach increases according to size change).
<ul><li>When mastered, gain the ability to choose size modification among [-1, 0, 1, 2, 3 blocks] increase while still keep the strength effect. Sneak-activate to turn off.</li></ul></li></ul>
