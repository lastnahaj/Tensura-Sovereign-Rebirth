<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p>!! Cannot activate while wearing armor, or while using other skin based armor granting skills (excluding <a class="mw-redirect" href="../../extra/strengthen-body/" title="Abilities/Skills/Strengthen Body">Strengthen Body</a>) !!
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - Grants the user armour with effectiveness dependent on their EP. Base is equal to Pure Magisteel, 400,000+ is equal to Adamantite, and 800,000+ is equal to Hihiirokane.</li></ul>
