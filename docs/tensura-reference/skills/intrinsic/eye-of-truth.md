<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - Grants the user perfect vision and can see through <b>ANY</b> illusion and concealment (e.g. <a class="mw-redirect" href="../../unique/falsifier/" title="Abilities/Skills/Falsifier">Falsifier</a>, <a class="mw-redirect" href="../../../battlewill/haze/" title="Abilities/Battlewills/Haze">Haze</a>, ...).
<ul><li>With this skill you can also tell if someone is faking something with <a class="mw-redirect" href="../../unique/falsifier/" title="Abilities/Skills/Falsifier">Falsifier</a></li>
<li>Acts like magic sense (night vision)</li></ul></li></ul>
<p><b>Cannot be used without Hero Egg or True Hero</b>
</p>
