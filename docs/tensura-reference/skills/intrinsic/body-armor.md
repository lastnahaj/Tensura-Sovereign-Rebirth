<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - On activation, place “Armoursaurous Armor” in all empty armour slots. Costs 50 MP and if removed from armour slots, they’re destroyed.
<ul><li>When activated while crouching, gives "Armoursaurous Gauntlet". Also a multi-tool</li></ul></li></ul>
