<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - On attacking or being attacked, ignores every Dodge, Crit Chance, and Dodge Avoidance abilities.</li></ul>
<p><b>Cannot be used without being a <a href="../../../core-mechanics/races-awakening/#True_Hero" title="Races/Awakening">True Hero</a>.</b>
