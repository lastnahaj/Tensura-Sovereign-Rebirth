<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - Increases damage dealt by Fire/Flame related attacks by 1.5x. Doesn't Stack with <a href="../flame-domination/" title="Flame Domination">Flame Domination</a></li>
<li>[Passive - In Slot] - <b>Coating</b>: If the user is on fire: On tools it grants an autosmelt effect (ores into bars, wood into charcoal); on attacking enemies (melee and bows), set the target on fire for 5 seconds (10 if mastered)</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Hold] - Breathes fire. If user is burning, extinguishes the flames. 0 MP
<ul><li>Can be used infinitely if user has lava in spatial storage</li></ul></li></ul>
