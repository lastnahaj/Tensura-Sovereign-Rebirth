<p>[Active, Press] Food Chain - When used normally, the Skill Menu opens allowing you to learn any skill from a Subordinate. (You can enable this to allow the learning of Uniques or Ultimates in the TRNightmareUltimateConfig). When shifted and used, it instead allows you to teach your Subordinate any of your skills. (Same configuration logic. You can config both what is allowed, or full disable them)
