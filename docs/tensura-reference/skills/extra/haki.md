<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Hold] -  25 MP each 20 ticks. When activated 5% Speed (10% with mastery), all mobs within a 30x30 radius are affected. With mastery, scroll while holding down the skill button to change the percentage of EP used for calculation. If their EP is =&lt;75% of the user's used EP, it does nothing. Otherwise, give 1 Fear level for each 20% difference with the used EP.</li></ul>
