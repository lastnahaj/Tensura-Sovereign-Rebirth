<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] - When activated, creates a screen overlay that displays information about the currently looked at block or mob in 5 blocks radius (10 with Mastery). Analysis Level 1 - Displays Name, HP, MP, AP, Armor Points, etc. With Mastery - Analysis Level 2, displays the skills of the target <b>Only Players</b> (except for skills flagged as mastered). If a target has greater than 1.5X (2X with Mastery) the player's EP, then only its base stats are shown (Name, HP, SHP, Armor).
<ul><li>Shift + Activate to change between Block Only Analysis, Entity Only Analysis or Both.</li></ul></li></ul>
