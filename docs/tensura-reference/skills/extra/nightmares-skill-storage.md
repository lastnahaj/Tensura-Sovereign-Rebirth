<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<p>[Active, Press] Skill Storage
When used, it will open up a menu containing all the skills you've owned at least one (permanently) after obtaining Shub-Niggurath. This lets you re-create the skill if you lose it, however it comes at the cost of Shub-Niggurath's Mastery. You can delete skills within it to gain mastery, however they cannot be obtained again without the usage of analysis, food chain or predation abilities.
[Active, Press] Skill Creation:
The user can create skills with Shub-Niggurath assuming they do not already have the skill. These skills are permanent, however they cannot become mastered and require an MP cost.
[Active, Press] Skill Duplication:
The user can open a Skill Duplication menu, which is full of skills they've made more than three times, all of these skills are able to be mastered, and do not cost MP to create for the user.
</p>
