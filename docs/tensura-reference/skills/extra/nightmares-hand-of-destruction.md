<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Hold] Divine Darkness - This is the same as Astarte's Divine Darkness, but only the beam.</li>
<li>[Active, Press] Divine Darkness Style - You can shift use thie move to swap between firing styles:
<ul><li>Barrage Shot - The user fires 12 beams at once.</li>
<li>Back Shot - The user fires a beam from behind the target.</li>
<li>Swarm Shot - The user fires 12 beams in the same fashion as Dimension Storm.</li></ul></li></ul>
