<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
2 Modes
</p>
<ul><li>Breaks the block the player is currently looking at, and give player the block like silk touch.</li>
<li>Holding down while looking at an entity (with a hitbox smaller than 1 block, 2 block with mastery, +3 block with <a href="../gravity-manipulation/" title="Gravity Manipulation">Gravity Manipulation</a> toggled / +5 block with <a href="../gravity-domination/" title="Gravity Domination">Gravity Domination</a> toggled) will move that entity to where the user looks (scroll down to change the range from 0 to 30) - Ineffective against some bosses and targets with <a href="../gravity-domination/" title="Gravity Domination">Gravity Domination</a> or <a href="../gravity-manipulation/" title="Gravity Manipulation">Gravity Manipulation</a> toggled.</li></ul>
