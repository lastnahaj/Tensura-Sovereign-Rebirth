<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Copilot - This is used to toggle on and off Copilot mode. This means that Wise Ego will utilize skills to automatically protect you at times.</li>
<li>[Active, Press] Control - When used, the user swaps control of their body over to the Wise Ego. The Wise Ego is capable of fighting and killing threats.</li></ul>
<h2><span class="mw-headline" id="Warning">Warning</span></h2>
<ul><li>To leave auto battle mode you will need to rejoin the world</li>
<li>Auto battle Mode is only compatible with a select number of skills, magics and battlewills, Check <a href="https://tensuranightmares.wiki.gg/wiki/Auto_Battle_Mode_Compatability" title="Auto Battle Mode Compatability">Auto Battle Mode Compatability</a></li></ul>
