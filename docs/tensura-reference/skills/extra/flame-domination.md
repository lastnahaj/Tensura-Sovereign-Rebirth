<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] - Increases damage dealt by Fire/Flame related attacks by 3x. Mastery grants Flame attack resistance/nullification degrade if the user has 800k EP. Doesn't Stack with <a class="mw-redirect" href="../flame-manipulation/" title="Abilities/Skills/Flame Manipulation">Flame Manipulation</a></li>
<li>[Passive - In Slot] - <b>Coating</b>: If the user is on fire: On tools it grants an autosmelt effect (ores into bars, wood into charcoal); on attacking enemies (melee and bows), set the target on fire for 10 seconds (20 if mastered).</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Hold] - When activated, If player is on fire, breath fire, distinguish the fire. 0MP
<ul><li>Can be used infinitely if the user has lava points in spatial storage</li></ul></li></ul>
