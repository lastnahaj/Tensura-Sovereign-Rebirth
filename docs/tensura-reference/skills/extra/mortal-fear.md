<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/>
</p>
<ul><li>50 MP per second for each subordinate. User's speed is reduced to 5% while active (10% with mastery). All mobs within a 10x10 radius of the user and user's subordinates are affected. If mob's EP is =&lt;75% of the user's EP, it does nothing. Otherwise, give 1 Fear level for each 20% difference in EP. With mastery, scroll while holding down the skill button to change the percentage of EP used for calculation. Additionally grants a Strength 4 effect (Strength 8 with mastery) to user's subordinates for 1 minute.</li></ul>
