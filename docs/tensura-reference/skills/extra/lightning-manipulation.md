<h2><span class="mw-headline" id="Extra_obtainment_method">Extra obtainment method</span></h2>
<p>Mastering 3 lightning skills, the following skills can be mastered to obtain the skill:
</p>
<ul><li><a href="../../intrinsic/thunder-breath/" title="Thunder Breath">Thunder Breath</a></li>
<li><a href="../black-lightning/" title="Black Lightning">Black Lightning</a></li>

<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><br/> <big> <b>Can only be used during a thunderstorm</b> </big>
</p><p><br/>
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] Increases damage dealt by Lightning related attacks by 1.5x. Doesn't stack with <a class="mw-redirect" href="../lightning-domination/" title="Abilities/Skills/Lightning Domination">Lightning Domination</a>.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active - Press] When activated, spawns lightning where you're looking, costing 20 MP.</li></ul>
