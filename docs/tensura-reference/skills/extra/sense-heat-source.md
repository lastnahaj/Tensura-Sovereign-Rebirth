<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive - Toggle] When toggled on, outlines entities flagged "warm blooded" and blocks that emit heat with a red outline in a 20 block Radius. When mastered, block outlines can be toggled off by activating the skill. Entities flagged Cold-blooded don't appear at all, and entities flagged Cold Source like Snow Golem will have cyan outline. Doesn't work in the nether.</li></ul>
