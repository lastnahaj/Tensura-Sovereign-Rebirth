<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, In Slot] Parallel Processing - Increases the amount of Learned Points and Mastery Points gained when learning/using Skills, Magic, Battlewill, and Arts by 14 (15 Total). The user can also cast more than one spell at a time.</li>
<li>[Passive, True] All of Creation - The user instantly learns all Aspectual Magic. The user instantly learns all Recipes.</li>
<li>[Passive, Toggled] Chant Annulment - For Magic, casting becomes instant. User will be able to cast magic even when air level is under max or silence effect is active. Enchantment particles are also reduced.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Knowledge Browsing - The user opens a menu containing a list of all the skills the target has learned. The user can use this to learn Resistances, Nullifications or Magics from the target.</li>
<li>[Active, Press] Concept Sharing - The user opens a menu containing a list of all the skills they have learned. The user can use this to teach Resistances, Nullifications or Magics to the target. If the target has Mastered Holy-Demonic Inversion, this instead shares the user's series of Magic Knowledge with the target, to evolve Holy-Demonic Inversion into <a href="../nightmares-necronomicon/" title="Necronomicon">｢ Necronomicon, Book of Magic ｣</a></li></ul>
