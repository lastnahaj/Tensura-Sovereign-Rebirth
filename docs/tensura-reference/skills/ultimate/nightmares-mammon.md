<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, In Slot] Absorb Life: While Mammon is in slot, the user's attacks will steal a small amount of MP, AP or Barrier Points.</li>
<li>[Passive, Toggled] Multilayer Barrier: When Toggled, the user will gain x2 their HP as Barrier Points. This will be removed upon being toggled off.</li>
<li>[Passive, True] All-Desire: The user gains permanent Hero Of The Village II. The user gains Desire for every two Villager Trade they do.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Hold] Control Heart: When held down and looking at a mob, put it under control after a certain amount of time passes. Base Value = 30 seconds. Being in a distance of 10 blocks decreases base value by 15 seconds and being at a distance over 40 blocks increases the value by 30 seconds [Max distance is 80 blocks]. When used against a mob rather than a player, it increases value by another 30 seconds. When used against players, it decreases the time by 1 second per 1 desire value. 1 desire value = 5 villager trades. Control time decreased by 2 seconds for each trade a trader mob has. [You must be looking at the target for the whole time or the timer will go down; Shift activate can release/free the controlled target]</li>
<li>[Active, Press] Feed Desire: When used while holding Emeralds, Magic Ore or Potions, the user will gain 1 Desire Point per item in hand, destroying the items in hand. When used without an item in hand, Feed Desire will spend 1 Desire Point per Effect and Effect Level on you, to remove any negative effects.</li>
<li>[Active, Toggle] Desire Manifestation: When used, the user will manifest their desire, increasing their Attack Damage and Armor by 1 for every 5 Desire Points they have. (2 for every 5 when mastered). If they have over 250 Desire Points, the user is immune to many effects.</li>
<li>[Active, Toggle] Mammon Flare: Must be sneaking to deactivate</li>
<li>[Active, Hold] Death Wish: If held down for 200 ticks while looking at a mob within 5 blocks, instantly kills them. Slows target by 60%. Costs 1000 MP [You must be looking at the target for the whole time or the timer will go down]. This becomes instant if you have 1,000 Desire Points but will use all of them.</li>
<li>[Active, Press] Skill Steal: The user can steal one Skill from a target. The tier of that skill is dependent off the user's Desire Points, and takes 10 Minutes to be copied. This uses the Desire Points.  If the user dies before the skill is analyzed, they lose the Desire Points and do not learn the skill (The Skill can be turned into a copy by turning MammonSkillTheft to False.)
<ul><li>The cost of skills goes like this:
<ul><li>Common: 5</li>
<li>Extra: 40</li>
<li>Intrinsic: 15</li>
<li>Resistance: 30</li>
<li>Unique: 5,000</li>
<li>Ultimate: 10,000</li></ul></li></ul></li></ul>
