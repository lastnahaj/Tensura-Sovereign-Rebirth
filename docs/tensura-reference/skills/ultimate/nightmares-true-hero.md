<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, Toggled] Banner of the Supreme King -The user's slain subordinates become a Memory. The user loses max EP equal to the subordinates EP. The Memory is automatically stored in [ Banner of the Supreme King ]</li>
<li>[Passive, In-Slot] Hero's Boons - Hero of the Village X Effect and Grants a permanent Luck X effect. The player and their allies have a 100% critical hit rate and a 25% auto-dodge chance.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Banner of the Supreme King - When used, open a menu (similar to Shadow Storage), which can only contain the Memory of your Subordinates. The first 9 Slots will count as the "Active" Memory, giving you the EP and Skills of the Subordinate. Any other slot is used as storage.</li>
<li>[Active, In-Slot] Lucky Field - The user's Luck is amplified by their happy mood, All nearby Allies with over 100,000 EP are given Inspiration 2. They will additionally nullify damage taken from any entity with less than 50% of the user of this skill's EP.. This is bypassed if the target possses an Ultimate Skill.</li>
<li>[Active, Hold] Hero's Haki</li>
<li>[Active, Press] Hero's Charisma - This functions the same as before, besides: Any mobs they or the player defeat will be resurrected as allies with max health (Except Undead). This only works while Hero's Charisma is in slot.</li>
<li>[Active, Press] Einherjar - The user can use this skill, while holding a Memory in hand. This will revive the subordinate with a higher level of sentience.</li></ul>
