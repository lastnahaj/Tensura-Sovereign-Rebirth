<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Deep Storage - The user is unable to have their skills copied or plundered. The user gains three additional skill slots. (Default Keybinds: F, G, H)</li></ul>
<h3><span class="mw-headline" id="Actives">Actives</span></h3>
<ul><li>[Active, Press] Skill Creation - When used, the player can select one Unique Skill or Anti-Skill to create. They will have this Unique Skill under the exchange it for a new one. When Astral Light is mastered, it is able to produce Ultimate Skills.</li>
<li>[Active, Press] Directive Imprint - When used, the player can select a skill they have created to imprint it with an "Ego". This Ego-Imprinted skill becomes permanent skill until the Directive Imprint is reused and the Ego is placed into another skill.
<ul><li>Skills under Directive Imprint will always be considered as if it was in-slot.</li></ul></li>
<li>[Active, In-Slot] Tachyon Processing - While this mode is In-Slot, the user gains +25 Mastery and +25 Learning.</li>
<li>[Active, Hold] Bodily Recreation - When held, after sixty seconds and slowly draining 5,000 MP a second, the user will forcefully evolve their race. This will have a long cooldown.</li></ul>
<p>[Active, Press] Material Creation - The user opens a Menu that lists all of the materials they've learned, and allows them to create them, by expending their Magicules. This takes Maximum Magicules away from the user for everything made. On Shift Use it will insted begin learning the item in hand or block the user is looking at.
</p>
