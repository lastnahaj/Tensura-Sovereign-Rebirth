<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True]  Heavenly Lord - The user becomes a Holy alignment. The user is considered Divine.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active,Press] Skill Evolution - When Pressed, the user opens up the Skill Designer GUI which will contain the various Skill Evolution options. Each Evolution option has various MP costs per. Skill Evolutions MP cost to attempt is offten equal to the Total MP of possible Skills, sometimes x2.</li>
<li>[Active, Press] Recycle - When Pressed, the user opens the Recycle GUI and can delete any of the skills they own for its Magicule Cost. There is a 15% Chance (20% when mastered) to get 10% more MP (20% when mastered) than the skills original cost.</li>
<li>[Active, Held] Magicule Furnace - When held, the user begins to generate Magicules, restoring 5% (7% when mastered). The user can generate current Magicules up to 250% of the user's Max Magicules.</li>
<li>[Active, Press] True Apocrypha - When pressed, the user toggles on the Apocrypha state, as the user begins to lose Magicules at 8% (6% when mastered) every two seconds. The user boosts their Attack Damage by 30 (60 when mastered) and armor by 35 (70 when mastered). While Apocrypha is active, the user bypasses Physical Attack Nullification.</li>
<li>[Active, Held] Divine Darkness - When held, the user fires a beam that deals 100 Holy and 100 Darkness Damage. (250 when mastered) a second and cost 3.5% MP per second fire. If the user Shift Presses this, it instead fires off a Divine Darkness Barrage and fires off twelve beams instead.</li></ul>
