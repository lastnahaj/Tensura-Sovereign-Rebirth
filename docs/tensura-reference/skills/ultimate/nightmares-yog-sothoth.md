<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Spacetime Manipulation:
<ul><li>Obtain the Spacetime Manipulation extra skill on obtainment</li></ul></li>
<li>[Passive, True] Absolute Coating:
<ul><li>The user gains 200 damage boost (250 when mastered) and applies Severance effect on hit, just like absolute severance</li></ul></li>
<li>[Passive, In-slot] Seize:
<ul><li>The user's attacks have a 50% chance to steal 1.5% MP from the target to restore their own MP</li></ul></li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[ Active - Press ] Rob (Just like from Usurper, but ignores EP requirement.)</li>
<li>[ Active - Press ] Copy (Just like Usurper but can gain Resistances.)</li>
<li>[ Active - Press ] Force Takeover (Just like Usurper but Spirit Takeover works up to 90% of the EP)</li></ul>
<ul><li>[Active, Press] Absolute End:
<ul><li>Launches an invisible projectile that deals 300 damage (400 when mastered)</li></ul></li></ul>
<ul><li>[Active, Press] Infinity Prison:
<ul><li>At the cost of 50,000MP + 10% of the Targets EP, imprisons the mob/player the player is looking at. Seals all movement, skill usage and healing. Drains MP from the trapped target at a rate of 100 per 10 ticks. Lasts for 300 seconds. Increases to 600 seconds with mastery - 20s cooldown - Goes on CD if you Miss (10s with Mastery).</li></ul></li></ul>
<p><br/>
</p>
<ul><li>[Active, Press] Time Leap:
<ul><li>The user can save the location they're at. If they are to die, they instead return to the saved Time Leap location, however all of Yog-Sothoth is set on a 500 second cooldown</li></ul></li></ul>
<ul><li>[Active, Press] Reverse Fate(Requires Mastery, Requires Learning:
<ul><li>When used, the user saves the current state of all things withing sixty blocks. On a second use, it loads everything back to that state. (3 minute cooldown.)</li></ul></li></ul>
<ul><li>[Active, Press] Time Stop (Requires Learning):
<ul><li>When used, it will stop time in the local area, rendering all things still. Time will be stopped for 10 Seconds.  (15 when mastered) Some entities can bypass this, and moved in Stopped Time, if they have mastered Spacetime Manipulation, Have a Time Manipulation Skill or are a Time Soul.</li></ul></li></ul>
