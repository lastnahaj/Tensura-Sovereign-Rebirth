<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<p>If you were to obtain a True Dragon Ultimate Skill after obtaining Azathoth, God of The Void, the user can use the command /trnightmare TrueDragonNucleation sacrifice Veldora/Velgrynd/Valzard/Velgaia to add it into the Azathoth Skill, however this cost 1,000,000 MP to do.
</p>
<ul><li>[Passive, True] Spacetime Manipulation - The user obtains Spacetime Manipulation, and when mastered, they obtain Spacetime Domination.</li>
<li>[Passive, Toggle] Null - The user bypasses Resistances and degrades Nullifications. The user is immune to Critical Hits. The user has 50% Dodge Chance negation.</li>
<li>[Passive, True] Nihility Bar - The user gains a new resource bar, it is a purple bar beside their MP and AP bar. It scales from 0 to 100,000 Nihility.</li></ul>
<h3><span class="mw-headline" id="Actives">Actives</span></h3>
<ul><li>[Active, Press] Imaginary Space - When used normally, this opens a 66 page spatial storage with a max stack size of 999. When shift used, this will warp the user into their Imaginary Space Dimension, if used next to players or entities, it will also pull them in.
<ul><li>While in the Imaginary Space, you can press this ability on someone normally to eject them out of the dimension, and shift use it to get out, or take people out of it with you.</li>
<li>Each person's Imaginary Space is different, can be built and lived it, without worry, as it is their own unique dimension.</li></ul></li>
<li>[Active, Held] Soul Gluttony - This is a powerul rending predation ability which slowly pulls things into it. It instantly kills any entity with less than 60% of the user's EP or an Ultimate Skill. This does 450 Spiritual Damage and 150 Void Damage</li>
<li>[Active Held] Darkest Void - The user produces a blackhole, similarly to Beelzebuth's, but when shift used, it begins to power the blackhole up, and can be thrown when release from shift held.
<ul><li>The Blackhole does 50 Spiritual Damage and 50 Void Damage, and has it's damage increased by the Soul Points the user has, up to a maximum of 250. When damaged, this will apply Soul Rot, making them unable to heal their Spiritual Health.</li></ul></li>
<li>[Active, Press] Multidimensional Barrier - The user creates a Barrier with x4 HP (6x when mastered) as well as the benefits of Fault Field while the user has the Barrier Points.</li>
<li>[Active, Held] Nihility Generation - When held the user begins to generate Nihility. This generates 500 Nihility per second. When mastered, if the user has a Raphael Manas, the manas can use Nihility Supply to make this passive.</li>
<li>[Active, In-Slot] Imaginary Blade - The user imbues their Nihility inside of their blade. It cost 1,500 Nihility per attack and deals 250 Void Damage per hit. Anything "killed" is instead pulled into the Imaginary Space. When mastered, this only requires 1,000 Nihility per attack.</li></ul>
<p>This can copy the skills of the target from Resistances to Extras when it sends them to the Imaginary Space.
</p>
<ul><li>[Active, Press] True Dragon Release - The user can shift between modes to select [ Storm / Scorch / Frost / Earth ] if they possess the different True Dragon.
<ul><li>This can be used to place the True Dragon into your Body, allowing them free roam, however unlike Dragon Summoning, the True Dragon Release variants have the ability to save the skills they possess, meaning they can obtain their evolved Ultimate Skills and use them.</li></ul></li>
<li>[Active, Held] True Dragon Nucleation - The user can begin producing a nucleation core in front of them. The user can shift between modes to select [ Storm / Scorch / Frost / Earth ] if they possess the different True Dragon.</li></ul>
<p>You can only make one True Dragon Nucleation Core of each type.
</p>
<h3><span class="mw-headline" id="Nuclation_Cores">Nuclation Cores</span></h3>
<ul><li>[Storm Nucleation Core]</li></ul>
<p>This core deals 50 Water, Wind, Lightning and Lightning Damage while in-slot.
</p>
<ul><li>[Scorch Nucleation Core]</li></ul>
<p>This core deals 200 Flame Damage while in-slot.
</p>
<ul><li>[Frost Nucleation Core]</li></ul>
<p>This core deals 200 Cold Damage while in-slot.
</p>
<ul><li>[Earth Nucleation Core]</li></ul>
<p>This core deals 100 Earth and 100 Gravity Damage while in-slot.
</p><p>None of these Damages are modified by Dominations or Manipulations.
</p>
<ul><li>[True Nucleation Core]</li></ul>
<p>When all four cores are slotted into the same item, they gain the following:
</p>
<ul><li>Soul Nucleation:</li></ul>
<p>The user produces an attack using the Nucleation Cores inside of the weapon alongside Azathoth's Nihility Collapse. This requires 50,000 Nihility but will produce powerful blackhole similarly to Darkest Void, but will also apply Black Burn, Chill, Overheat and Anti-Skill.
</p>
<ul><li>Overheat is a new status effect which reduces the target's Attack Damage by 10 per level.</li></ul>
