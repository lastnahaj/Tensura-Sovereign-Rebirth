<ul><li>Method One:
<ul><li>When the user has two Ultimate Skills, not including Uriel, and the user has 100 Skills Mastered.</li></ul></li></ul>
<ul><li>Method Two:
<ul><li>The user alters Uriel, Lord of Oaths into Raguel, to evolve it into Cthuga for another player, which will evolve Uriel, Lord of Oaths into Shub-Niggurath, King of Harvest</li></ul></li></ul>

<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Skill Storage
<ul><li>When used, it will open up a menu containing all the skills you've owned at least one (permanantly) after obtaining Shub-Niggurath. This lets you re-create the skill if you lose it, however it comes at the cost of Shub-Niggurath's Mastery. You can delete skills within it to gain mastery, however they cannot be obtained again without the usage of analysis, food chain or predation abilities.</li></ul></li></ul>
<ul><li>[Active, Press] Skill Creation:
<ul><li>The user can create skills with Shub-Niggurath assuming they do not already have the skill. These skills are permanent, however they cannot become mastered and require an MP cost.</li></ul></li></ul>
<ul><li>[Active, Press] Skill Duplication:
<ul><li>The user can open a Skill Duplication menu, which is full of skills they've made more than three times, all of these skills are able to be mastered, and do not cost MP to create for the user.</li></ul></li></ul>
<p><br/>
</p>
<ul><li>[Active, Press] Skill Gifting:
<ul><li>The user can attempt to bestow a skill they have analyzed inside of Skill Storage, this works fine for all non-Unique and Ultimate Skills. If you attempt to bestow a Unique or Ultimate Skill, both the user and target loose the MP cost of the ability, and there is a chance the target is not compatible with that skill. (80% chance) meaning it will be removed on death and cannot be mastered.</li></ul></li></ul>
<p>They can only be compatible with one skill.
</p>
