<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, In Slot]  Precision Miner - The user gains the effects of Fortune 2 and Luck 5.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Kiln - This mode acts and functions like a portable kiln. It is however 4x faster than a kiln.</li>
<li>[Active, Press] Refine - This mode acts like Great Sage's refining and crafting, however is 4x faster</li>
<li>[Active, Press] Smithing - All tools crafted from it have their EP set to 500,000 by default.</li>
<li>[Active, Press] Craftmens - his mode acts as the same Godly Craftsmen Menu, however it can stack items to 700, and has a third tab, permitting the engravement of skills onto items.</li></ul>
