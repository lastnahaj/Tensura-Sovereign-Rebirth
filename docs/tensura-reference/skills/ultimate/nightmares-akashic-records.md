<h2><span class="mw-headline" id="Usage">Unverified upstream effects</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, Toggled] Know It All - The user gains +35 Mastery and +35 Learning. They gain 75% Melee and Projectile Dodge Chance. 100% Crit Modifer.</li>
<li>[Passive, True] Deep Storage - The user is unable to have their skills copied or plundered. The user gains three additional skill slots.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Skill Creation - When used, the player can select one Unique Skill, Utlimate Skill or Anti-Skill to create. They can create up to three skills at a time. The oldest skill will be removed each time a "fourth" skill would be created. This usually follows a config, however [ Informational Understanding ] can bypass this.</li>
<li>[Active, Hold] Informational Understanding - When held, the user begins to record the information of an entity, this allows all of their skills to be learned by the user, however Unique and Ultimate Skills are stored inside of [ Skill Creation ]. Skills can be put on a Blacklist to prevent [ Informational Understanding ] from being able to store them.</li>
<li>[Active, Press] Star King Creation - When used, you create a Star King Vessel for ???. This form permits them to be fully sentient. If used while a Manas Player is bound to you, the Manas' name is changed to ???, and they enter the Star King Vessel.</li>
<li>[Active, Press] Godly Body - When pressed, the user will lose 1,500,000 MP and will forcefully evolved into a <a href="https://tensuranightmares.wiki.gg/wiki/Races/1.21.1/God_Man" title="Races/1.21.1/God Man">God Man</a> Race.</li>
<li>[Active, Hold] Residual Breeder Reactor - While held down, gives the player MP equal to 5% (10% at Mastery) of their maximum every 115 Ticks. This allows the user to exceed their MP cap, similar to Wrath and Satanael, however is refined and doesn't have the user go rampant, however due to this, the user's MP cannot exceed 525%.</li>
<li>[Active, Press] Star Order - When used, the user can push ???'s focus into a specific created skill, similarly to Directive Imprint, however, Star Order makes it so the skills previous benefits from Directive Imprint is doubled.</li>
<li>[Active, Press] Information Re-Creation - The user opens a menu that allows them to create skills, similar to Astarte / Astaroth's Skill Mapping.</li>
<li>[Active, Press]Material Creation - This is like the Intrinsic Skill: "<a href="../../intrinsic/nightmares-material-creation/" title="Material Creation">Material Creation</a>", however it functions with an instant learning mechanic. You can simply put the item into it, and be able to re-create it.</li></ul>
