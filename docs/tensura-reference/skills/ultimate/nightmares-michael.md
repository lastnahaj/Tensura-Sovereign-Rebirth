<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, In-slot] Castle Guard:
<ul><li>While this mode is in slot, the user is rendered immune to all forms of Skills, Magic and Battlewills. The user cannot use Skills, Magic or Battlewills while this mode is active. The user suffers the same penalty, as they cannot use any Skills, Magic or Battlewills, however they can attack and use Haki. This mode can only be active for 3 minutes. The user needs at least 3 Subordinates to make Castle Guard work.</li></ul></li></ul>
<p>(The castle guard can be bypassed by Nova Break.)
</p>
<ul><li>[Active, Held] Armageddon:
<ul><li>The user presses and holds this ability for 20 seconds (5 when mastered) and summons 3 Seraph Angels (summons 6 when mastered). These angel Seraphs are subordinates who can help you.</li></ul></li></ul>
<p>(The Angel Knights have 500 (1000 when mastered) hp. They have access to holy attack resistance, light attack resistance, and all light magic spells.)
</p>
<ul><li>[Active, Held] Held] Regalia Dominion:
<ul><li>The user holds this ability for 60 seconds. (30 when mastered) to make a target a temporary subordinate. If the target's naming is on, this allows the user to name the subordinate, without paying the MP Cost. The user needs 20% EP more than the target to work.</li>
<li>When the user possess a Stage 4 Ego for Michael, or a Manas with 250+ Admiration, this ability can be used instantly, unless the target has a Sin Skill.</li></ul></li></ul>
<ul><li>[Active, Press] Ultimate Dominion:
<ul><li>The user can press and use Ultimate Dominion to open a menu to collect any of the skills that their subordinate with a Virtue Skill possess. When this is used, Ultimate Dominion will kill the Ego of any skills it copies, placing the EgoKilled tag on both the Owner of Michael and the Subordinate target. Regardless of if the user attempts to or not, when Ultimate Dominion is used, it will copy all of the Virtue Skills on the subordinate, marking their Egos dead. If Ultimate Dominion is used a target with a Virtue Skill that is a Manas, the Virtue Skill cannot be copied by Michael.</li>
<li>If the owner of the Michael Skill possess the Unique Skill: Unyielding or the Ultimate Skill: Sariel, and collect 1,500 Bond Points with a subordinate, they are able to use Ultimate Dominion on a subordinate that doesn't possess a Virtue Skill.</li></ul></li></ul>
<ul><li>[Active, Press] Alternative(Requires Ego):
<ul><li>This mode is gained by evolving Dominator while in possession of a developed Ego. When you use this ability, you'll bestow Alternative to a target, giving them a random variant of Alternative to your subordinate.</li>
<li>If this is used on a mob, it will also gain sentience. If this is Shift Used, it will revoke the Alternative</li></ul></li>
<li>[Active, Press] Ultimate Enchantment(Requires Ego):</li></ul>
<p>The user opens a menu to gift a temporary Ultimate Skill to a subordinate.
</p>
