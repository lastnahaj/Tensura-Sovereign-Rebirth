<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Obtaining_Composite_Data">Obtaining Composite Data</span></h3>
<p>Courage: Is obtained by using Yog-Sothoth's Usurper abilities on a player or target with Chosen One, True Hero, Lord of Heroes or Sacred Haki.
Justice: Is obtained by using Yog-Sothoth's Usurper abilities on a player or target with Dominator or Michael.
Hope: Is obtained by using Yog-Sothoth's Usurper abilities on a player or target with Unyielding or Sariel.
</p>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Spacetime Domination - When Spacetime Manipulation is mastered, the user obtains Spacetime Domination.</li>
<li>[Passive, Toggle] Absolute Coating - The user gains 250 Damage Boost (300 when mastered) and applies Severance Effect on hit, just like Absolute Severance.</li></ul>
<h3><span class="mw-headline" id="Actives">Actives</span></h3>
<ul><li>[Active, In-Slot] Usurping - The user's attacks have a 50% chance to steal 2% MP from the target to restore their own MP.</li>
<li>[Active, In-Slot] Absolute - Blocks all attacks with a formula of C = A * 15. C = Cost, A = Attack Damage. Attacks from an opponent with 75% or higher the user's EP can bypass it.</li>
<li>[Active, Press] Usurping - You can change the mode by using Shift + Press. While this mode is in-slot, [ Usurping ] is active. It has the following modes:</li></ul>
<p>Robbery: The user can use Robbery on any target, to steal one of their skills. All Stolen Skills are temporary, only lasting for twenty minutes. This cannot copy Ultimate Skills.
Takeover: The user can use Takeover on any target, not just summoins, permitting Yog-Sotohort to temporary take over any target without Spiritual Attack Nullification or higher MP than the target's EP.
</p>
<ul><li>[Active, Press] Absolute - The user can swap between two modes. When this slot is in mode [ Absolute ] is in Slot.
<ul><li>Projectile: The user fires a severance cutter. It does 650 Damage.</li>
<li>Imprison: At the cost of 50,000MP + 10% of the Targets EP, imprisons the mob/player the player is looking at. Seals all movement, skill usage and healing. Drains MP from the trapped target at a rate of 100 per 10 ticks.    Lasts for 300 seconds. Increases to 600 seconds with mastery - 20s cooldown - Goes on CD if you Miss (10s with Mastery).</li></ul></li>
<li>[Active, Press] Courage - The user can swap between modes. The user gains two of these modes randomly when obtaining Yog-Sotohort.
<ul><li>Hero's Haki</li>
<li>Hero's Charisma</li>
<li>Lucky Field</li></ul></li>
<li>[Active, Press] Justice - The user can swap between modes. The user gains two of these modes randomly when obtaining Yog-Sotohort.
<ul><li>Castle Guard</li>
<li>Armageddon</li>
<li>Regalia Dominion</li>
<li>Ultimate Dominion</li></ul></li>
<li>[Active, Press ] Hope - The user can swap between modes. The user gains two of these modes randomly when obtaining Yog-Sotohort.
<ul><li>Life Domination</li>
<li>Empower</li>
<li>Fortitude</li>
<li>Life Domination</li>
<li>Reconstruction</li></ul></li></ul>
