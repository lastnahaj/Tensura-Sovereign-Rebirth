<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, In Slot] Arroganz - The user now will be able to copy an ability's specific mode after being hit or affected by it when [Lucifer]'s Arroganz Mode is in slot. Skilles copied by Pride, Lucifer or Nodens' Ultimate Arroganz cannot possess Egos.</li>
<li>[Passive, In-Slot (Mastery)] Countermeasure - When the user learns a Skill that inflicts a target with a Status Condition, the user becomes Immune to that Status Condition.</li>
<li>[Passive - Toggle (Requires Infinity Prison or uriel)(Mastery Required)] Castle Breaker - The user is able to bypass Absolute Guard from Infinity Prison and Uriel.</li></ul>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Arroganz - Opens a new GUI that allows the user to quickly equip or remove copied ability modes.</li></ul>
