<h2><span class="mw-headline" id="Spawn">Spawn</span></h2>
<p>This spirit spawns upon the first stage in a fight with <a href="../mobs-hinata-sakaguchi/" title="Mobs/Hinata Sakaguchi">Hinata Sakaguchi</a>
</p><p>However, you can also summon this spirit (if you have it) yourself, using <a class="mw-redirect" href="../../magic/summon-greater-elemental/" title="Abilities/Magics/Summon Greater Elemental">Summon Greater Elemental</a><br/>
<i>However, this will not give any drops and killing it using this method does not count towards boss-fight quests or evolution requirements.</i>
</p><p>Will not naturally spawn with Majin alignment.
</p>
<ul><li><ul><li>Being named by a Majin will change its alignment to Majin</li></ul></li></ul>
