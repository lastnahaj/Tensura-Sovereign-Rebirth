<h1><span class="mw-headline" id="Info">Info</span></h1>
<h4><span class="mw-headline" id="An_otherworlder_that_hates_slimes..."><i>An otherworlder that hates slimes...</i></span></h4>
<p>A Rare Otherworlder, upon near death triggers the release of <a href="../mobs-ifrit/" title="Mobs/Ifrit">Ifrit</a> - After Ifrit's defeat, Shizu will appear defeated and slowly dying.<br/>
<b>Shizu cannot be tamed</b>
</p>
<h2><span class="mw-headline" id="Spawn">Spawn</span></h2>
<p>A Rare Boss that has a 3.33% chance to spawn instead of an otherworlder. <br/>
<i>(1/30 chance for an otherworlder to spawn)</i>
</p>
