<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p><i>To activate, right click the Kiln to open the menu</i>
</p><p><a class="image" href="https://tensura.wiki.gg/wiki/File:Kiln_GUI.png" title="Kiln GUI"><img alt="Kiln GUI" data-file-height="333" data-file-width="503" decoding="async" height="333" loading="lazy" src="../../../assets/upstream/tensura/items/kiln-gui-80a8a29c5e.png" width="503"/></a>
</p><p><i>Middle Slot is for the Output, There are arrows either side to swap which item you wish to meld.</i>
</p><p><i>Right Side - Top is for what you wish to Smelt</i>
</p><p><i>Right Side - Bottom is for your fuel</i>
</p><p><br/>
The Kiln smelt raw <span class="nowrap"><span class="sprite-file"><a href="../../magic/magic-ore-shard/" title="Magic Ore Shard"></a></span> <a href="../../magic/magic-ore-shard/" title="Magic Ore Shard"><span class="sprite-text">Magic Ore Shard</span></a></span>, creating Molten Magisteel. The Molten Magisteel can then be used to make <span class="nowrap"><span class="sprite-file"><a href="../../items/pure-magisteel-ingot/" title="Pure Magisteel Ingot"></a></span> <a href="../../items/pure-magisteel-ingot/" title="Pure Magisteel Ingot"><span class="sprite-text">Pure Magisteel Ingot</span></a></span> / <span class="nowrap"><span class="sprite-file"><a href="../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"></a></span> <a href="../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"><span class="sprite-text">Pure Magisteel Nugget</span></a></span>. Mixing the Molten Magisteel with other materials like Iron, Gold and Silver will create other metal types. <br/>
Such as:
</p>
<ul><li><span class="nowrap"><span class="sprite-file"><a href="../../items/low-magisteel-ingot/" title="Low Magisteel Ingot"></a></span> <a href="../../items/low-magisteel-ingot/" title="Low Magisteel Ingot"><span class="sprite-text">Low Magisteel Ingot</span></a></span> / <span class="nowrap"><span class="sprite-file"><a href="../../items/low-magisteel-nugget/" title="Low Magisteel Nugget"></a></span> <a href="../../items/low-magisteel-nugget/" title="Low Magisteel Nugget"><span class="sprite-text">Low Magisteel Nugget</span></a></span></li>
<li><span class="nowrap"><span class="sprite-file"><a href="../../items/high-magisteel-ingot/" title="High Magisteel Ingot"></a></span> <a href="../../items/high-magisteel-ingot/" title="High Magisteel Ingot"><span class="sprite-text">High Magisteel Ingot</span></a></span> / <span class="nowrap"><span class="sprite-file"><a href="../../items/items-misc-high-magisteel-nugget/" title="High Magisteel Nugget"></a></span> <a class="mw-redirect" href="../../items/items-misc-high-magisteel-nugget/" title="High Magisteel Nugget"><span class="sprite-text">High Magisteel Nugget</span></a></span></li>
<li><span class="nowrap"><span class="sprite-file"><a href="../../items/pure-magisteel-ingot/" title="Pure Magisteel Ingot"></a></span> <a href="../../items/pure-magisteel-ingot/" title="Pure Magisteel Ingot"><span class="sprite-text">Pure Magisteel Ingot</span></a></span> / <span class="nowrap"><span class="sprite-file"><a href="../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"></a></span> <a href="../../items/pure-magisteel-nugget/" title="Pure Magisteel Nugget"><span class="sprite-text">Pure Magisteel Nugget</span></a></span></li>

<li><span class="nowrap"><span class="sprite-file"><a href="../../items/orichalcum-ingot/" title="Orichalcum Ingot"></a></span> <a href="../../items/orichalcum-ingot/" title="Orichalcum Ingot"><span class="sprite-text">Orichalcum Ingot</span></a></span> / <span class="nowrap"><span class="sprite-file"><a href="../../items/orichalcum-nugget/" title="Orichalcum Nugget"></a></span> <a href="../../items/orichalcum-nugget/" title="Orichalcum Nugget"><span class="sprite-text">Orichalcum Nugget</span></a></span></li></ul>
