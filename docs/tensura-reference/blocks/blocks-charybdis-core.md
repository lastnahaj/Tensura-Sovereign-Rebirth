<p>Found inside the Core room of the <a href="../../structures/structures-charybdis-cave/" title="Structures/Charybdis Cave">Charybdis Cave</a> and used to summon <a href="../../bosses/mobs-charybdis/" title="Mobs/Charybdis">Charybdis</a>.
</p><p>The core must consume 100K EP before being left clicked to summon the boss. To consume EP the Core must be placed down within a 16 block radius while you kill a mob, mobs killed within its radius won't give you and EP and will not drop exp.
