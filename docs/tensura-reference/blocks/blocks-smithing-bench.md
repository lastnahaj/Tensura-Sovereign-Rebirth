<h1><span class="mw-headline" id="Usage">Usage</span></h1>
<p>The <a class="mw-selflink selflink">Smithing Bench</a> is used to make a variety of Tensura:Reincarnated Armor, Gear and other special items. Most of the gear created with the Smithing Bench is unlocked through <a class="mw-redirect" href="../../items/items-learnable/" title="Items/Schematics">Schematics</a>.
