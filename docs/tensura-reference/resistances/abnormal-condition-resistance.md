<p><b>Abnormal Condition Resistance</b> is a <b>Resistance Skill</b> in Tensura: Reincarnated.
</p>
<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p>When toggled, it <b>nullifies</b> the effects of <b>Hunger, Poison, Blindness, Confusion, Darkness, Mining Fatigue, Slowness, Weakness, <a href="../../core-mechanics/effects-burden/" title="Effects/Burden">Burden</a>, <a href="../../core-mechanics/effects-fragility/" title="Effects/Fragility">Fragility</a> and Curse</b>.
</p>
<h2><span class="mw-headline" id="Tips">Tips</span></h2>
<ul><li>Go to the Spirit Tree and get someone else to hit you with Darkness Cannon or Haki if possible</li></ul>
<ul><li>Getting attacked by a <a href="../../mobs/mobs-basilisk/" title="Mobs/Basilisk">Basilisk</a>.</li></ul>
