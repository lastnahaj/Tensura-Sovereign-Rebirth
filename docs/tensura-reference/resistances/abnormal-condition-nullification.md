<h2><span class="mw-headline" id="Effect">Effect</span></h2>
<p>When toggled, it <b>nullifies</b> the effects of <b>Hunger</b>, <b>Poison</b>, <b>Blindness</b>, <b>Confusion</b>, <b>Darkness</b>, <b>Mining</b> <b>Fatigue</b>, <b>Slowness</b>, <b>Weakness</b>, <a href="../../core-mechanics/effects-burden/" title="Effects/Burden"><b>Burden</b></a>, <a href="../../core-mechanics/effects-fragility/" title="Effects/Fragility"><b>Fragility</b></a> and <b>Curse</b>, <a href="../../core-mechanics/effects-fatal-poison/" title="Effects/Fatal Poison"><b>Fatal Poison</b></a>, <a href="../../core-mechanics/effects-paralysis/" title="Effects/Paralysis"><b>Paralysis</b></a>, <b>Hypnosis</b> and <b><a href="../../core-mechanics/effects-petrification/" title="Effects/Petrification">Petrification</a></b>.
</p><p>Nullifies <a href="../../core-mechanics/damage-types/#Abnormal" title="Damage Types"><span>Abnormal</span></a> Damage
<br/>
Infection is unaffected by this
<br/>
</p>
