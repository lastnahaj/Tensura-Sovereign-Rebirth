<h2><span class="mw-headline" id="Server_Config_Folder">Server Config Folder</span></h2>
<p>Some configs don't get automatically synced from a server to their players so this is needed. On the other hand, having different config on different worlds seems to be more fun.
</p><p>If you don't have a world created, go into "defaultconfigs" instead of "configs", this will contain default configs that will be applied to any world you will create. If you do, go to "saves" (or "world"), select your world then check "serverconfig", the TR configs will be there.
