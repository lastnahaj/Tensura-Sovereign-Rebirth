<h3><span class="mw-headline" id="Other_purposes">Other purposes</span></h3>
<ul><li>Can modify the size of player <a href="../../races/races-slime/" title="Races/Slime">Slimes</a> by consuming one with <a class="mw-redirect" href="../../skills/intrinsic/absorb-dissolve/" title="Abilities/Skills/Absorb &amp; Dissolve">Absorb &amp; Dissolve</a> (use it normally to get bigger, shift while doing it to get smaller)
<ul><li>Growing will increase maximum HP by 5</li>
<li>Limit up to 300% growth (Not Confirmed)</li>
<li>you lose your extra Health and Size if you die</li></ul></li></ul>
<p><br/>
</p>
<ul><li>Can feed it to a pet <a href="../../mobs/mobs-slime/" title="Mobs/Slime">Slime</a> to increase their size (unless it's a <a href="../../mobs/mobs-metal-slime/" title="Mobs/Metal Slime">Metal Slime</a>)</li></ul>
