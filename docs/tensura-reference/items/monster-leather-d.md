<h2><span class="mw-headline" id="Use">Use</span></h2>
<h3><span class="mw-headline" id="Crafting">Crafting</span></h3>
<p>Can be used to create an armor of Monster Leather of Rank-D.
The recipe is the same as the one of the leather of the vanilla game. It must be used in a <a href="../../blocks/blocks-smithing-bench/" title="Blocks/Smithing Bench">Smithing Bench</a> after unlocking the <a href="../items-schematics-monster-leather-gear-schematic/" title="Items/Schematics/Monster Leather Gear Schematic">Monster Leather Gear Schematic</a>.
</p>
