<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p>Resets <b>EVERYTHING</b> from the User, Pretty much like reincarnating from scratch.<br/>
<big>This also means <b>achievements</b> that you've obtained.</big>
<br/>
Also used for the <a href="../../core-mechanics/mechanics-reset-counter/" title="Mechanics/Reset Counter">Reset Counter</a> gamerule mechanic
</p>
<ul><li>5 second cooldown</li></ul>
