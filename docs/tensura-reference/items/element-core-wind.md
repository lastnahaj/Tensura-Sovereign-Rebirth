<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p>Used for slotting <br/>
Effects: Grants a special attack that fires a straight wind projectile dealing 30 damage. Adds elemental damage to the weapon: +30 for the first core and +15 for each additional core equipped.
</p>
