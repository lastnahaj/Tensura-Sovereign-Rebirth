<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<p>This item can be used to obtain any <a href="../items-misc/#Elemental" title="Items/Misc">elemental core</a> by right clicking the respective spirit (water, fire, earth, etc).
</p><p>An Empty Element Core can also be inserted into an item enchanted with <a class="new" href="https://tensura.wiki.gg/wiki/Enchantments?action=edit&amp;redlink=1" rel="nofollow" title="Enchantments (page does not exist)">Slotting</a>, but it is <b>not</b> recognised as an element. It occupies a slot and loses durability like any other core while contributing nothing to a combination, so it should not be used as filler.
</p>
<h2><span class="mw-headline" id="Elemental_core_combinations">Elemental core combinations</span></h2>
<p><a class="new" href="https://tensura.wiki.gg/wiki/Enchantments?action=edit&amp;redlink=1" rel="nofollow" title="Enchantments (page does not exist)">Slotting</a> (maximum level <b>III</b>, main hand only, applicable to items in the <code>tensura:handheld_enchantable</code> tag) allows one elemental core to be inserted per enchantment level. Cores are inserted by right clicking the core onto the item in the inventory, and removed by right clicking the item onto an empty slot.
</p><p>Combinations are matched by the <b>exact number of cores of each element</b>. An item with Slotting III can therefore use a one- or two-core combination by simply leaving the remaining slots empty. Any set of cores that does not match a registered combination does nothing at all.
</p>
<h3><span class="mw-headline" id="Melee_bonus">Melee bonus</span></h3>
<p>Every melee hit with the enchanted item deals bonus elemental damage on top of the normal attack, once per element listed in the combination:
</p>
<pre>bonus damage = attack damage × element multiplier × (0.2 + attack charge² × 0.8)
</pre>
<p>The bonus is dealt as magic damage (90% Spiritual, 10% Aspectual), so it ignores armour but is reduced by elemental and magic resistances. Attacking with an uncharged attack bar retains only 20% of the bonus. The hit does not trigger if the target's invulnerability timer is at 40 or above. Each hit costs the listed durability from <b>every</b> core inserted.
</p>
<h3><span class="mw-headline" id="Casting">Casting</span></h3>
<p>Holding right click for at least 10 ticks (0.5 seconds) and releasing fires the combination's projectile. Projectile damage is a multiplier applied to the user's weapon damage, and the cast costs the listed durability from every inserted core.
</p><p>Combinations marked as having no projectile still work in melee, but the cast produces nothing except the sound of breaking and the full durability cost, and their melee cost is also far higher.
</p>
<h3><span class="mw-headline" id="Core_durability">Core durability</span></h3>
<p>Each elemental core has 500 durability and is fire resistant. Cores inserted into an item in the <code>tensura:infinity_elemental_cores</code> tag never lose durability; that tag currently points at <code>#tensura:hihiirokane_items</code>, so any <a class="new" href="https://tensura.wiki.gg/wiki/Materials?action=edit&amp;redlink=1" rel="nofollow" title="Materials (page does not exist)">Hihiirokane</a> tool or weapon uses its cores indefinitely.
</p>
