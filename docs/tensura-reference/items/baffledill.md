<h2><span class="mw-headline" id="Description">Description</span></h2>
<p>Baffledills apply the <a href="../../core-mechanics/effect-hypnosis/" title="Effect/Hypnosis"> Hypnosis</a> to all players within 8 blocks of the flower. Non-default alignments (majin/holy/chaos) and spiritual beings are unaffected.
</p>
<h2><span class="mw-headline" id="Obtainment">Obtainment</span></h2>
<p>Found in forest biomes.
</p>
<ul><li><ul><li>If shears are used on the baffledill, it will no longer release <a href="../../core-mechanics/effect-hypnosis/" title="Effect/Hypnosis"> Hypnosis</a> into the area.</li></ul></li></ul>
<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<ul><li>Can be used to create a <a class="new" href="https://tensura.wiki.gg/wiki/Items/Consumables/Hypnosis_Potion?action=edit&amp;redlink=1" rel="nofollow" title="Items/Consumables/Hypnosis Potion (page does not exist)"> Hypnosis Potion</a> like a vanilla potion.
<ul><li>When brewed with a fermented spiders eye it will create a <a class="new" href="https://tensura.wiki.gg/wiki/Items/Consumables/Hypnotic_Efficiency_Potion?action=edit&amp;redlink=1" rel="nofollow" title="Items/Consumables/Hypnotic Efficiency Potion (page does not exist)"> Hypnotic Efficiency Potion</a></li></ul></li></ul>
