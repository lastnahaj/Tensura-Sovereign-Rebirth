# Ascension & Awakening

**Tensura: Ascension** owns the primary late-game Unique-to-Ultimate progression layer.

The base mod's [Awakening](tensura-reference/core-mechanics/races-awakening.md) article is kept separate from this TSR addon layer.

## Intended progression

**High EP**<br>
+ **True Demon Lord or True Hero status where required**<br>
+ **mastered prerequisite skill**<br>
+ **awakening resources / tribute**<br>
+ **Ascension mechanics**<br>
→ **Ultimate-level progression**

Ascension is also important because it provides Tensura-scale support for multiple external boss mods.

## Balance policy

Ultimate progression is never sold in the Shop and is not handed out as a routine FTB reward.

Exact thresholds and reward values will be finalized after server balance testing.
