# Progression Overview

The intended high-level character arc is:

**Reincarnation**<br>
→ **Early survival**<br>
→ **Race development**<br>
→ **Skill acquisition/mastery**<br>
→ **Guild progression**<br>
→ **Gear evolution**<br>
→ **Subordinates and naming**<br>
→ **Settlement / nation**<br>
→ **Regional bosses and other worlds**<br>
→ **Demon Lord Seed / Hero candidate**<br>
→ **True Demon Lord / True Hero**<br>
→ **Ascension / Ultimate Skills**<br>
→ **Prestige / Soul Grade / mastery endgame**

## Parallel progression tracks

TSR deliberately supports several parallel tracks:

| Track | Primary system |
|---|---|
| Character power | Tensura Reincarnated |
| Prestige / NG+ | SlimeThrone Extras |
| Ultimate awakening | Ascension |
| Equipment | Gear Evolution + Metalworks |
| Adventure | Guild + bosses + dimensions |
| Civilization | MineColonies + Tensura x MineColonies |
| Personal storage | Sophisticated Backpacks |
| Base storage | Sophisticated Storage |
| Campaign | FTB Quests |
| Repeatable objectives | SlimeThrone Extras |
| Economy | Quest Shop |

The objective is for these systems to reinforce each other without forcing every player into the same playstyle.
