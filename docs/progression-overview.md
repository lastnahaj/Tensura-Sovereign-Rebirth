## The main progression loop

<ol class="progression-route" aria-label="TSR character progression route">
  <li><strong>Reincarnate</strong><span>Read your race, starting abilities, and resource limits.</span></li>
  <li><strong>Develop</strong><span>Earn EP, evolve your race, acquire skills, and raise mastery.</span></li>
  <li><strong>Awaken</strong><span>Reach major race milestones such as True Demon Lord or True Hero.</span></li>
  <li><strong>Qualify</strong><span>Meet the required RE, quests, boss kills, and maximum evolution.</span></li>
  <li><strong>Preserve</strong><span>Spend EP and Soul Grade to lock eligible skills you want to keep.</span></li>
  <li><strong>Prestige</strong><span>Use a Character Reset Scroll and begin another route with permanent progress.</span></li>
</ol>

!!! important "Prestige is a reset, not a normal evolution"
    Confirm every requirement and lock any eligible skills you intend to retain before using the Character Reset Scroll. TSR's current configuration does not ignore locked skills during reset.

## What controls each part?

| Player activity | Installed system | What it contributes |
|---|---|---|
| Race, EP, awakening, and core skills | Tensura: Reincarnated | The main character-power foundation |
| Prestige, Soul Grade, skill locks, and repeatable objectives | SlimeThrone Extras 2.1.2.1 | The long-term reincarnation loop |
| Missions, contracts, coins, and deployable characters | Beyond Adventures 1.1.9 | A separate objective and reward loop |
| Additional late-game race and skill routes | Installed Tensura content add-ons | Integrated into the normal Races and Abilities areas |
| Equipment and civilization | Gear, storage, and colony systems | Parallel progression that supports a character build |

## Version boundary

This guide is scoped to TSR's installed **Minecraft 1.21.1** files. It includes Beyond Adventures 1.1.9 and SlimeThrone Extras 2.1.2.1. It does **not** describe Tensura: Dungeon, dungeon floors, Colosseum systems, Dungeon NPC shops, or related gamerules because that separate mod is not present in the current pack.
