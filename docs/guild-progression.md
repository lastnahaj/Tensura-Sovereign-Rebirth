# Guild Progression

**TenSura Guild** provides the adventurer progression track.

The intended campaign uses the Guild as the bridge between early survival and larger world threats:

**Early commissions**<br>
→ **Free Guild discovery**<br>
→ **Adventurer ranks**<br>
→ **harder hunts/exploration**<br>
→ **boss assignments**<br>
→ **late-game guild challenges**

The Guild branch is separate from MineColonies so players can pursue adventure progression without immediately becoming a nation builder.
