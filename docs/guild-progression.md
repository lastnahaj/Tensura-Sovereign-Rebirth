# Retired guild integration

TenSura Guild has been removed. Its adventurer ranks, commissions, and Guild-specific progression are no longer part of the current TSR guide.

Adventure progression continues through the independently documented [quests](quests-and-shop.md), [boss encounters](bosses-and-dimensions.md), and [exploration systems](adventure-travel-and-loot/index.md). These are not described as replacements for the removed mod's exact mechanics.

The [recorded mod inventory](current-modlist.md) may still include historical entries; it does not restore this retired gameplay system.
