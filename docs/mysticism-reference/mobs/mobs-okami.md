<h2><span class="mw-headline" id="Info">Info</span></h2>
<p>A mob useful if player wants to be a Tengu race.
</p>
<h2><span class="mw-headline" id="Spawn">Spawn</span></h2>
<p>This mob spawns in meadows, snowy slopes, jagged peaks, frozen peaks and stony peaks.
Can only spawn when a chunk is initially loaded for the first time.
</p>

</p>
