<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Active">Active</span></h3>
<ul><li>[Active, Press] Dissolve - When skill toggled on, allows the player to rescind the contract.</li></ul>
<ul><li>[Active, Press] Contract - Allows the user to establish a contract with another player. Using the skill will create a prompt on the target's screen if it's a player and ask them if they would like to contract with you. Fails if the target has a contract with a higher level spirit than the element you currently embody.
<ul><li>If accepted, allow the user to switch the modes of the skill and enters spectator mode on the target player instantly. Grants the target different spells depending on the evolution you are at.</li></ul></li></ul>
<ul><li>[Active, Press] Force Summon - Forcibly summons yourself in Spiritual Mode to assist your contractor.</li></ul>
<p>BEWARE: If the host dies to void damage...this kills both the contracter and contracted. Wee Woo. Even across dimensions. The spirit does not have to be in spectator for this to happen.
</p>
