<h2><span class="mw-headline" id="Usage">Usage</span></h2>
<h3><span class="mw-headline" id="Passive">Passive</span></h3>
<ul><li>[Passive, True] Nine Lives:</li></ul>
<p>The player can respawn up to nine times if the world is set to hardcore. Check current lives using /tensura get ability check mysticism:schrodinger.
</p>
<ul><li>[Passive, True] Dead or Alive:</li></ul>
<p>There is a 50% chance that the user does not lose Energy (and by extension, souls) when dying.
</p>
<ul><li>[Passive, Toggle] Feline Instincts:</li></ul>
<p>The player's safe falling distance has been increased by 32 blocks. This means you will need to fall 32 blocks before you start taking half a heart of fall damage, etc. etc.
</p>
<ul><li>[Passive, In Slot] Poison Touch:</li></ul>
<p>On hurting an enemy, apply Poison II to the target. On mastery, this becomes Fatal Poison II.
<br/>
</p>
