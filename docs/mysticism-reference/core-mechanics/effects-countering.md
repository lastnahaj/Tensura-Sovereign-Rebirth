<h2><span class="mw-headline" id="Causes">Causes</span></h2>
<p>Countering is caused by activating the ability "Counter" with <a href="../../skills/unique/restricted/" title="Restricted">Restricted</a>.
</p>
<h2><span class="mw-headline" id="Effects">Effects</span></h2>
<ul><li>Attack speed <b>decrease</b> by 100% (Disabled attack speed)</li>
<li>Movement speed <b>decrease</b> by 100% (Disabled movement speed)</li>
<li>When damaged, <b>stops</b> the effect and gives the <a href="../effects-imbalanced/" title="Effects/Imbalanced">Imbalanced</a> effect to the attacker.</li></ul>
<h2><span class="mw-headline" id="Info">Info</span></h2>
<p>This effect is technically categorised "neutral", but so is <a class="external text" href="https://minecraft.wiki/w/Water_Breathing" rel="nofollow">Water Breathing</a>
</p>
