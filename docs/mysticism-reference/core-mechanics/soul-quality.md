<h2><span class="mw-headline" id="Functionality">Functionality</span></h2>
<p>The soul quality determines how many ultimate skills one soul can be engraved with.
</p><p>Upon reincarnating trough any means, you gain a soul quality.
These are the probabilities to gain each soul quality.
</p>
<ul><li>10.99% - 0</li>
<li>32.97% - 1</li>
<li>27.47% - 2</li>
<li>16.48% - 3</li>
<li>05.49% - 4</li>
<li>03.30% - 5</li>
<li>02.20% - 6</li>
<li>01.10% - 7</li></ul>
<p>This is a gamerule, meaning the number of ultimate skills is only limited, if this gamerule is set to 'true'
</p>
